# 🌐 Bảng Tra Cứu 30+ Network Ports & Protocols Bắt Buộc Thuộc - Chuyên Sâu Mạng Máy Tính Cho DevOps

> 💡 **Bản chất 1 câu**: Hệ thống hóa toàn bộ các Port tiêu chuẩn Well-known Ports (0-1023) và Registered Ports (1024-49151) thường dùng nhất trong DevOps.  
> 🎯 **Trọng tâm thực chiến DevOps**: Thuộc lòng các Port dịch vụ: SSH 22, HTTP 80, HTTPS 443, DNS 53, DHCP 67/68, MySQL 3306, Postgres 5432, Redis 6379, K8s API 6443.

---

## 1. 🧠 Hình Hình Dung Nhanh (Intuitive Mindset)

Số Port như số phòng trong khách sạn: Khách sạn có địa chỉ IP `10.0.0.1`. Phòng 22 là lễ tân SSH, phòng 80/443 là nhà hàng Web, phòng 3306 là kho dữ liệu MySQL.

---

## 2. 📚 Lý Thuyết Chuyên Sâu & Bản Chất Mạng (Under The Hood Architecture)

### 2.1 Bảng Phân Loại Cổng Mạng (Network Port Ranges)
- **Well-known Ports (0 - 1023)**: Dành riêng cho các dịch vụ hệ thống cốt lõi (Cần quyền root để bind).
- **Registered Ports (1024 - 49151)**: Dành cho các ứng dụng phần mềm đăng ký (MySQL, Redis, Postgres).
- **Dynamic / Ephemeral Ports (49152 - 65535)**: Dành cho cạc mạng Client ngẫu nhiên mở ra làm Port nguồn.

## 5. 🚀 Bộ Câu Hỏi Phỏng Vấn DevOps & Network Thực Tế (Interview Q&A)

> **Q: Tại sao DNS lại sử dụng cả 2 giao thức UDP 53 và TCP 53?**  
> **A**: UDP 53 dùng cho các truy vấn tên miền tiêu chuẩn (Query ngắn < 512 bytes). TCP 53 dùng cho đồng bộ dữ liệu giữa các máy chủ DNS (Zone Transfer AXFR) hoặc câu trả lời DNS lớn.

> **Q: Port mặc định của Kubernetes API Server là bao nhiêu?**  
> **A**: Là Port `6443` TCP.
