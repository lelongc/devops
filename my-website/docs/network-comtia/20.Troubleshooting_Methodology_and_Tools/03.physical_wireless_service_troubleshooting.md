# 🌐 Kịch Bản Chẩn Đoán Sự Cố Mạng Thực Tế (Troubleshooting Scenarios) - Chuyên Sâu Mạng Máy Tính Cho DevOps

> 💡 **Bản chất 1 câu**: Tổng hợp các kịch bản xử lý sự cố mạng thực tế: Lỗi cáp vật lý (Crosstalk, Attenuation), sự cố Wi-Fi (Nhiễu kênh), xung đột địa chỉ IP, cạn dải DHCP, Routing Loops, MTU Mismatch & Broadcast Storms.  
> 🎯 **Trọng tâm thực chiến DevOps**: Troubleshooting sự cố IP Duplicate, DHCP exhaustion, Routing loop, MTU mismatch (PMTU Discovery failure), VOIP jitter và Broadcast storm.

## 1. 🧠 Hình Hình Dung Nhanh (Intuitive Mindset)

Sự cố MTU Mismatch như chiếc xe tải quá khổ chui qua hầm chui: Gói tin kích thước 1500 bytes chứa cờ Don't Fragment đi qua đường hầm VPN có MTU 1420 bytes -> Gói tin bị vỡ nát ngầm làm đứt kết nối ứng dụng.

## 2. 📚 Lý Thuyết Chuyên Sâu & Bản Chất Mạng (Under The Hood Architecture)

### 2.1 Các Kịch Bản Sự Cố Mạng Thường Gặp & Cách Khắc Phục

1. **Sự Cố Xung Đột Địa Chỉ IP (Duplicate IP Address)**:
   - **Triệu chứng**: 2 máy tính cùng được gán 1 địa chỉ IP -> Kết nối mạng bị chập chờn liên tục rớt ping.
   - **Xử lý**: Kiểm tra bảng ARP Cache bằng `ip neighbor`. Đổi IP tĩnh hoặc xóa lease trong DHCP Server.
2. **Sự Cố Cạn Dải Địa Chỉ IP DHCP (DHCP Pool Exhaustion)**:
   - **Triệu chứng**: Máy tính mới cắm dây nhận địa chỉ IP APIPA (`169.254.x.x`).
   - **Xử lý**: Kiểm tra file `dhcpd.leases`, tăng thời gian nhàn rỗi giải phóng IP (Lease time) hoặc mở rộng dải IP Range.
3. **Sự Cố Sai Khớp Kích Thước MTU (MTU Mismatch / PMTUD Failure)**:
   - **Triệu chứng**: Ping gói tin nhỏ thông bình thường, nhưng khi tải file lớn hoặc kết nối SSH/HTTPS thì bị treo cứng đơ!
   - **Nguyên nhân**: Đường truyền VPN/GRE chèn thêm Header làm vượt quá MTU 1500 bytes nhưng Router lại chặn gói tin ICMP Path MTU Discovery.
   - **Xử lý**: Hạ MTU trên card mạng xuống `1420` hoặc `1400` bytes: `ip link set dev eth0 mtu 1420` hoặc bật cờ `TCP MSS Clamping` trên Firewall.
4. **Sự Cố Vòng Lập Routing (Routing Loop)**:
   - **Triệu chứng**: Lệnh `traceroute` hiển thị gói tin chạy qua chạy lại kẹt giữa 2 IP Router liên tục cho tới khi hết TTL.
   - **Xử lý**: Sửa lại bảng tuyến đường Static Route hoặc kiểm tra cấu hình OSPF/BGP.

## 3. ⚡ Bảng Tra Cứu Câu Lệnh & Khái Niệm Thực Hành (Reference Table)

| Công cụ / Lệnh / Khái niệm | Tham số / Flag / Protocol | Giải thích ý nghĩa chi tiết | Ứng dụng thực tế trong DevOps / Network |
| :--- | :--- | :--- | :--- |
| **`Duplicate IP`** | `L3 Error` | 2 thiết bị trùng IP làm rớt kết nối chập chờn | `Kiểm tra ARP table và DHCP pool` |
| **`DHCP Exhaustion`** | `L7 Error` | Hết IP khả dụng trong pool làm client nhận APIPA 169.254 | `Mở rộng dải IP range / Giảm lease time` |
| **`MTU Mismatch`** | `L3 Error` | Sai lệch MTU làm đứt kết nối khi truyền file lớn | `Chỉnh MTU 1420 hoặc bật TCP MSS Clamping` |
| **`Routing Loop`** | `L3 Error` | Gói tin chạy lặp vòng tròn giữa 2 Router | `Kiểm tra traceroute và sửa Routing Table` |

## 4. 🛠 Thao Tác Thực Chiến & Kịch Bản DevOps (Real-World Scenarios)

### 🛠 Các lệnh thực hành gõ là ăn ngay:
```bash
# Debug sự cố MTU Mismatch bằng lệnh ping cấm phân đoạn (-M do):
ping -M do -s 1472 8.8.8.8 # 1472 + 28 bytes IP/ICMP Header = 1500 bytes MTU

# Nếu bị lỗi 'Frag needed', hạ dần kích thước gói tin để tìm MTU chuẩn!
```

### 🚀 Kịch bản xử lý sự cố thực tế khi đi làm:
Troubleshoot lỗi SSH/Web bị treo cứng khi kết nối qua IPSec VPN Tunnel:
# Hạ MTU trên giao diện VPN interface xuống 1412 bytes và ép MSS Clamping:
sudo iptables -t mangle -A FORWARD -p tcp --tcp-flags SYN,RST SYN -j TCPMSS --clamp-mss-to-pmtu

## 5. 🚀 Bộ Câu Hỏi Phỏng Vấn DevOps & Network Thực Tế (Interview Q&A)

> **Q: Triệu chứng đặc trưng nào giúp nhận biết sự cố sai lệch MTU (MTU Mismatch)?**  
> **A**: Ping gói tin nhỏ (mặc định) thông bình thường, nhưng khi thực hiện giao dịch nạp dữ liệu lớn (như tải file, HTTPS handshake hoặc SSH) thì kết nối bị treo đơ không phản hồi.

> **Q: Làm sao phát hiện sự cố Routing Loop giữa các Router bằng dòng lệnh?**  
> **A**: Sử dụng lệnh `traceroute <destination_IP>`, nếu thấy gói tin chạy lặp lại liên tục qua lại giữa 2 địa chỉ IP Router thì chắc chắn đang bị Routing Loop.

## 6. 📝 Cheat Sheet & Ghi Nhớ Nhanh (Summary)

- [x] IP Duplicate: Trùng IP rớt mạng (Check ARP)
- [x] DHCP Exhaustion: Nhận IP 169.254 APIPA
- [x] MTU Mismatch: Treo khi truyền file lớn (Sửa MTU 1420 / TCPMSS)
- [x] Routing Loop: Traceroute thấy IP chạy lặp lại
