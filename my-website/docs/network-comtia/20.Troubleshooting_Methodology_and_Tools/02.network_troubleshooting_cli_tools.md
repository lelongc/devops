# 🌐 Bộ Công Cụ CLI Chẩn Đoán Sự Cố Mạng (tcpdump, nmap, ip, dig) - Chuyên Sâu Mạng Máy Tính Cho DevOps

> 💡 **Bản chất 1 câu**: Thành thạo bộ công cụ dòng lệnh CLI chẩn đoán sự cố mạng kinh điển: `ip`, `ping`, `traceroute`, `dig`, `nslookup`, `arp`, `ss`, `tcpdump`, `nmap` và `mtr`.  
> 🎯 **Trọng tâm thực chiến DevOps**: Sử dụng nâng cao tcpdump (bắt packet theo host/port/flag), nmap (scan port), dig (query DNS), ss (check ports/sockets), mtr (check latency/loss).

---

## 1. 🧠 Hình Hình Dung Nhanh (Intuitive Mindset)

Bộ công cụ CLI chẩn đoán mạng như túi cứu thương của bác sĩ ngoại khoa: `ping` để thử phản xạ, `ss` kiểm tra nhịp tim các cổng, `tcpdump` như máy siêu âm soi từng tế bào gói tin đang chạy trên cáp.

---

## 2. 📚 Lý Thuyết Chuyên Sâu & Bản Chất Mạng (Under The Hood Architecture)

### 2.1 Bảng Tra Cứu Bộ Lệnh CLI Troubleshooting Mạng Thần Thánh

```bash
# 1. Kiểm tra thông số IP và Cạc mạng
ip addr show
ip -s link show eth0 # Xem thống kê số gói tin lỗi/drop

# 2. Kiểm tra Routing & Gateway
ip route show

# 3. Tra cứu ARP Cache
ip neighbor show

# 4. Kiểm tra thông mạng & Latency/Loss
ping -c 5 8.8.8.8
mtr --report --report-cycles 10 8.8.8.8 # Công cụ kết hợp ping + traceroute cực mạnh

# 5. Phân tích đường đi Hops
traceroute -n google.com

# 6. Kiểm tra các Port đang Listen và Socket kết nối
sudo ss -tulpn
sudo lsof -i :443

# 7. Test kết nối Port từ xa (TCP Handshake)
nc -zvw3 10.0.0.10 3306

# 8. Tra cứu bản ghi DNS chi tiết
dig @8.8.8.8 google.com A +short

# 9. Quét Port & Dịch vụ mạng bằng Nmap
nmap -sV -p 22,80,443,3306 10.0.0.10

# 10. Bắt gói tin mạng trực tiếp với tcpdump
sudo tcpdump -i eth0 -nn 'tcp port 80 and host 192.168.1.50' -w http.pcap
```

---

### 2.2 Kỹ Thuật Bắt Gói Tin Mạng Chuyên Sâu Với `tcpdump`
- `tcpdump -i eth0`: Bắt gói tin trên cạc eth0.
- `-nn`: Không phân giải IP sang Hostname và không đổi Port sang Tên dịch vụ (Giúp lệnh chạy cực nhanh).
- `host 10.0.0.1`: Chỉ bắt gói tin có IP nguồn/đích là `10.0.0.1`.
- `port 443`: Chỉ bắt gói tin HTTPS.
- `src net 192.168.1.0/24`: Bắt gói tin từ dải mạng nguồn.
- `-w file.pcap`: Ghi dữ liệu thô ra file pcap để mở bằng phần mềm đồ họa **Wireshark**.

## 3. ⚡ Bảng Tra Cứu Câu Lệnh & Khái Niệm Thực Hành (Reference Table)

| Công cụ / Lệnh / Khái niệm | Tham số / Flag / Protocol | Giải thích ý nghĩa chi tiết | Ứng dụng thực tế trong DevOps / Network |
| :--- | :--- | :--- | :--- |
| **`ip`** | `iproute2` | Quản lý IP, cạc mạng, routing table và ARP | `ip addr, ip route, ip neigh` |
| **`ping / mtr`** | `ICMP Tool` | Kiểm tra độ trễ latency và tỉ lệ mất gói packet loss | `mtr --report 8.8.8.8` |
| **`nc (netcat)`** | `L4 Tool` | Test thấu cổng TCP/UDP từ xa cực nhanh | `nc -zvw3 10.0.0.1 3306` |
| **`dig`** | `DNS Tool` | Tra cứu bản ghi DNS chi tiết chuyên sâu | `dig google.com MX` |
| **`tcpdump`** | `Packet Sniffer` | Bắt và phân tích gói tin mạng theo thời gian thực | `tcpdump -i eth0 port 80` |
| **`nmap`** | `Network Scanner` | Quét port mở và nhận diện dịch vụ mạng | `nmap -sV 10.0.0.10` |

## 4. 🛠 Thao Tác Thực Chiến & Kịch Bản DevOps (Real-World Scenarios)

### 🛠 Các lệnh thực hành gõ là ăn ngay:
```bash
# Script chẩn đoán sự cố mạng tổng thể 1-liner:
ip addr && ip route && ping -c 3 8.8.8.8 && nc -zvw3 google.com 443
```

### 🚀 Kịch bản xử lý sự cố thực tế khi đi làm:
Sự cố ứng dụng không kết nối được tới Database PostgreSQL từ xa:
# Step 1: Test L3 -> ping 10.0.1.50
# Step 2: Test L4 Port 5432 -> nc -zvw3 10.0.1.50 5432
# Step 3: Bắt gói tin xem có bị Firewall DROP gói SYN không:
sudo tcpdump -i eth0 -nn 'host 10.0.1.50 and port 5432'

## 5. 🚀 Bộ Câu Hỏi Phỏng Vấn DevOps & Network Thực Tế (Interview Q&A)

> **Q: Lệnh `mtr` mang lại ưu điểm vượt trội gì so với lệnh `ping` hay `traceroute` riêng lẻ?**  
> **A**: Lệnh `mtr` kết hợp cả `ping` và `traceroute`, liên tục gửi gói tin để đo lường tỷ lệ mất gói (Loss %) và độ trễ (Latency) chi tiết tại từng Hop trên đường truyền.

> **Q: Cờ `-nn` trong lệnh `tcpdump` có tác dụng gì quan trọng?**  
> **A**: Cờ `-nn` ngăn `tcpdump` phân giải địa chỉ IP sang Hostname và số Port sang Tên dịch vụ, giúp tiết kiệm tải CPU và hiển thị output tức thì.
