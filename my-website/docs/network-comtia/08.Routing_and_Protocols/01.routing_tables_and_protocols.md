## 1. 🧠 Hình Hình Dung Nhanh (Intuitive Mindset)

Định tuyến Router như chọn bản đồ đường đi: OSPF như bản đồ Google Maps trong thành phố (Link-State chọn đường ngắn nhất). BGP như bản đồ hàng không quốc tế (Path-Vector định tuyến giữa các quốc gia / ISP lớn).

## 2. 📚 Lý Thuyết Chuyên Sâu & Bản Chất Mạng (Under The Hood Architecture)

### 2.1 Bảng Administrative Distance (AD) Độ Ưu Tiên Đường Đi
Khi Router học cùng 1 tuyến đường từ nhiều nguồn khác nhau, Router chọn đường đi từ nguồn có **Administrative Distance (AD) NHỎ NHẤT**:

| Nguồn tuyến đường (Route Source) | Giá trị AD (Administrative Distance) | Mức độ tin cậy |
| :--- | :--- | :--- |
| **Directly Connected** | **0** | Đăng tin cậy tuyệt đối |
| **Static Route** | **1** | Rất cao (Do Admin chỉ định) |
| **eBGP (External BGP)** | **20** | Định tuyến giữa các ISP |
| **EIGRP (Internal)** | **90** | Chuẩn độc quyền Cisco |
| **OSPF** | **110** | Chuẩn mở phổ biến nhất trong LAN/Corporate |
| **RIP** | **120** | Cổ điển (Dựa theo số Hops) |
| **iBGP (Internal BGP)** | **200** | BGP nội bộ |

---

### 2.2 So Sánh Các Giao Thức Định Tuyến Động (Dynamic Routing)
1. **OSPF (Open Shortest Path First - Link-State)**:
   - Sử dụng thuật toán Dijkstra tìm đường ngắn nhất (Cost dựa trên Bandwidth).
   - Phân chia thành các vùng **Areas** (Area 0 là Backbone Area).
   - Hội tụ (Convergence) rất nhanh, dùng làm nội mạng Doanh nghiệp / Datacenter.
2. **BGP (Border Gateway Protocol - Path-Vector)**:
   - Giao thức định tuyến duy nhất chạy trên **Internet Toàn Cầu** nối giữa các nhà mạng ISP (Autonomous Systems - AS).
   - Định tuyến dựa trên chính sách (Policy-based) và đường đi qua các AS Path.
3. **Cơ Chế NAT (Network Address Translation) & PAT (Port Address Translation)**:
   - **SNAT (Source NAT)**: Đổi IP nguồn Private LAN thành IP Public để ra Internet.
   - **DNAT (Destination NAT)**: Đổi IP/Port đích từ ngoài vào Server nội bộ (Port Forwarding).
   - **PAT (Port Address Translation / Masquerade)**: Gom hàng nghìn IP Private ra ngoài bằng **DUY NHẤT 1 IP Public** nhờ phân biệt qua các số Port nguồn ngẫu nhiên!

| Công cụ / Lệnh / Khái niệm | Tham số / Flag / Protocol | Giải thích ý nghĩa chi tiết | Ứng dụng thực tế trong DevOps / Network |

## 4. 🛠 Thao Tác Thực Chiến & Kịch Bản DevOps (Real-World Scenarios)

### 🛠 Các lệnh thực hành gõ là ăn ngay:
```bash
# xem bảng định tuyến Kernel Routing Table:
ip route show

# Thêm Static Route tới dải IP 10.200.0.0/16 qua Gateway 192.168.1.254:
sudo ip route add 10.200.0.0/16 via 192.168.1.254 dev eth0
```

### 🚀 Kịch bản xử lý sự cố thực tế khi đi làm:
Sự cố mạng chập chờn do lặp tuyến đường (Routing Loop):
# Kiểm tra đường đi thực tế của gói tin qua từng Hop bằng traceroute:
traceroute -n 8.8.8.8

## 5. 🚀 Bộ Câu Hỏi Phỏng Vấn DevOps & Network Thực Tế (Interview Q&A)

> **Q: Số Administrative Distance (AD) của OSPF và Static Route lần lượt là bao nhiêu?**  
> **A**: Static Route có AD = **1**, OSPF có AD = **110** (AD nhỏ hơn được ưu tiên hơn).

> **Q: Cơ chế PAT (Port Address Translation / Masquerade) giúp giải quyết vấn đề gì?**  
> **A**: Cho phép hàng nghìn máy tính dùng IP Private cùng truy cập Internet đồng thời qua duy nhất một địa chỉ IP Public nhờ phân biệt theo các số Port nguồn ngẫu nhiên.

## 6. 📝 Cheat Sheet & Ghi Nhớ Nhanh (Summary)

- [x] AD nhỏ hơn = Ưu tiên hơn (Connected 0, Static 1, BGP 20, OSPF 110)
- [x] OSPF: Link-State cho nội bộ LAN
- [x] BGP: Path-Vector cho Internet ISP
- [x] PAT/Masquerade: Dùng 1 IP Public cho cả LAN
