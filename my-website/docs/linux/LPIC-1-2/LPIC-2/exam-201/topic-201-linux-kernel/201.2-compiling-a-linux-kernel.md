# 🐧 Objective 201.2: Biên Dịch Kernel Linux Từ Source Code - Bản Chất Hệ Thống LPIC-2 & Thực Chiến DevOps

> 💡 **Bản chất 1 câu**: Quy trình tải source code, cấu hình (`make menuconfig`), biên dịch Kernel (`make`), cài đặt modules và cập nhật Bootloader.  
> 🎯 **Trọng tâm phỏng vấn Senior DevOps / SysAdmin**: Nguồn source Kernel (kernel.org), make menuconfig, make xconfig, make oldconfig, make, make modules_install, make install, zcat /proc/config.gz.

## 1. 🧠 Hình Hình Dung Nhanh (Intuitive Mindset)

Biên dịch Kernel như may một bộ vest đo riêng: Loại bỏ tất cả vải thừa (driver phần cứng không dùng tới) để Kernel nhỏ gọn nhất, chạy nhanh nhất và bảo mật nhất.

---

## 2. 📚 Lý Thuyết Chuyên Sâu & Bản Chất Hệ Thống (Under The Hood Mechanics - LPIC-2 Official Study Guide)

### 2.1 Quy Trình Biên Dịch Kernel Linux Chuẩn
1. **Chuẩn Bị Source Code & File Cấu Hình**:
   - Tải source từ `kernel.org`, giải nén vào `/usr/src/linux/`.
   - Copy file cấu hình hiện tại: `cp /boot/config-$(uname -r) .config` hoặc `zcat /proc/config.gz > .config`.
2. **Cấu Hình Kernel Features (`make menuconfig`)**:
   - Giao diện ncurses chọn tính năng:
     - `[*]` (Built-in): Biên dịch trực tiếp vào tệp ảnh Kernel `vmlinuz`.
     - `<M>` (Module): Biên dịch thành file `.ko` nạp động khi cần.
     - `[ ]` (Disabled): Loại bỏ khỏi Kernel.
   - `make oldconfig`: Chỉ hỏi các tính năng mới so với file `.config` cũ.
3. **Biên Dịch & Cài Đặt (Compilation & Installation)**:
   - `make -j$(nproc)`: Biên dịch Kernel core và modules sử dụng tất cả CPU Cores.
   - `sudo make modules_install`: Copy các file `.ko` vào `/lib/modules/VERSION/`.
   - `sudo make install`: Copy `vmlinuz`, `initramfs`, `System.map` vào `/boot/` và tự động gọi `update-grub`.

## 5. 🚀 Bộ Câu Hỏi Phỏng Vấn DevOps & SysAdmin Thực Tế (Interview Q&A)

> **Q: Trong `make menuconfig`, ký hiệu `[*]` và `<M>` khác nhau như thế nào?**  
> **A**: `[*]` biên dịch trực tiếp vào tệp ảnh Kernel `vmlinuz` (Built-in); `<M>` biên dịch thành file `.ko` nạp động (Module).

> **Q: File nào lưu trữ cấu hình biên dịch Kernel hiện tại?**  
> **A**: File `.config` tại gốc cây mã nguồn Kernel (hoặc `/boot/config-xxx`).
