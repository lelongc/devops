## 1. 🧠 Hình Hình Dung Nhanh (Intuitive Mindset)

Bảo trì đĩa như bảo dưỡng xe định kỳ: `tune2fs` cho phép chỉnh sửa bình xăng dự trữ (Reserved blocks), `btrfs scrub` như máy quét tự động phát hiện và sửa các vết xước dữ liệu bị hỏng ngầm (Bit rot).

## 2. 📚 Lý Thuyết Chuyên Sâu & Bản Chất Hệ Thống (Under The Hood Mechanics - LPIC-2 Official Study Guide)

### 2.1 Tinh Chỉnh & Sửa Lỗi Hệ Thống Tệp Cao Cấp
1. **Tinh Chỉnh Ext4 Vượt Trỗi Với `tune2fs`**:
   - Mặc định Ext4 dành riêng **5% dung lượng** cho user `root` (Reserved blocks). Trên đĩa dữ liệu 2TB, 5% = 100GB bị lãng phí!
   - `tune2fs -m 1 /dev/sdb1`: Giảm reserved blocks xuống 1%.
   - `tune2fs -l /dev/sdb1`: Xem superblock metadata của Ext4.
2. **Quy Trình Sửa Lỗi XFS Với `xfs_repair`**:
   - XFS KHÔNG dùng `fsck.xfs`. Nếu XFS bị corrupt:
     1. Unmount phân đĩa: `umount /dev/sdb1`.
     2. Kiểm tra & sửa lỗi: `xfs_repair /dev/sdb1`.
     3. Nếu hỏng nặng log journal: `xfs_repair -L /dev/sdb1` (Xóa log journal để ép mount lại).
3. **Phát Hiện Hỏng Dữ Liệu Ngầm Btrfs (`btrfs scrub`)**:
   - `btrfs scrub start /mountpoint`: Chạy ngầm đọc toàn bộ data block và kiểm tra mã checksum SHA256/CRC32C. Nếu phát hiện data bị lỗi (Bit rot), Btrfs tự động lấy bản sao lành lặn từ RAID sửa lại.

## 4. 🛠 Thao Tác Thực Chiến & Kịch Bản DevOps (Real-World Scenarios)

### 🛠 Các lệnh thực hành & Cấu hình chuẩn Production:
```bash
# 1. Thu hồi 4% dung lượng lãng phí trên đĩa dữ liệu Ext4 1TB:
sudo tune2fs -m 1 /dev/sdb1

# 2. Sửa lỗi đĩa XFS bị hỏng journal log:
sudo umount /data
sudo xfs_repair -L /dev/sdb1
sudo mount /dev/sdb1 /data
```

### 🚀 Kịch bản xử lý sự cố thực tế khi đi làm:
Giải phóng hàng trăm GB dung lượng bị giữ bởi Reserved blocks trên Server Log:
sudo tune2fs -m 0 /var/log_disk

## 5. 🚀 Bộ Câu Hỏi Phỏng Vấn DevOps & SysAdmin Thực Tế (Interview Q&A)

> **Q: Tham số `tune2fs -m 1` có tác dụng gì quan trọng trong quản trị lưu trữ?**  
> **A**: Giảm tỷ lệ dung lượng đĩa dành riêng cho Root (Reserved blocks) từ 5% xuống 1%, giải phóng dung lượng lãng phí trên các ổ đĩa lớn.

> **Q: Lệnh nào dùng để sửa lỗi ổ đĩa định dạng XFS?**  
> **A**: Sử dụng lệnh `xfs_repair` (chú ý BẮT BUỘC phải unmount đĩa trước khi chạy).
