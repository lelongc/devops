# 🐧 Objective 205.1: Mạng Máy Tính Nâng Cao & Cấu Hình Giao Diện (ip, route) - Bản Chất Hệ Thống LPIC-2 & Thực Chiến DevOps

> 💡 **Bản chất 1 câu**: Thành thạo công cụ bộ lệnh `iproute2` (`ip addr`, `ip route`, `ip link`), cấu hình Routing Table, ARP Cache và debug giao thức mạng.

## 1. 🧠 Hình Hình Dung Nhanh (Intuitive Mindset)

Bộ lệnh `iproute2` là dao Thụy Sĩ về mạng trên Linux: Thay thế hoàn toàn các lệnh cổ điển `ifconfig`, `route`, `arp` bằng bộ lệnh tập trung `ip` hiện đại.

---

## 2. 📚 Lý Thuyết Chuyên Sâu & Bản Chất Hệ Thống (Under The Hood Mechanics - LPIC-2 Official Study Guide)

### 2.1 Kiến Trúc Bộ Lệnh `iproute2` Thay Thế Legacy Net-tools

| Lệnh Legacy (Cổ điển) | Lệnh `iproute2` (Hiện đại) | Chức năng nâng cao |
| :--- | :--- | :--- |
| `ifconfig` | `ip addr` / `ip link` | Quản lý địa chỉ IP, cờ giao diện, MTU |
| `route -n` | `ip route` | Quản lý bảng tuyến đường Routing Table & Gateway |
| `arp -an` | `ip neighbor` / `ip neigh` | Xem và thao tác bảng phân giải địa chỉ MAC ARP Cache |
| `netstat -tulpn` | `ss -tulpn` | Truy vấn danh sách Socket kết nối thời gian thực |

---

### 2.2 Quản Lý Bảng Tuyến Đường (Routing Table)
- **Default Gateway**: Tuyến đường mặc định `0.0.0.0/0` đẩy mọi traffic không thuộc mạng nội bộ ra Internet.
- **Thêm Static Route**: `ip route add 10.200.0.0/16 via 192.168.1.254 dev eth0`.
- **Xóa Route**: `ip route del 10.200.0.0/16`.


---

## 3. ⚡ Bảng Tra Cứu Câu Lệnh & Cấu Hình Thực Hành (CLI Reference)

| Câu lệnh / Component | Tham số / Option | Giải thích ý nghĩa chi tiết | Ví dụ thực tế trong DevOps / SysAdmin |
| :--- | :--- | :--- | :--- |
| **`ip addr`** | `Quản lý địa chỉ IP trên các card mạng` | show, add, del | `ip addr add 192.168.1.50/24 dev eth0` |
| **`ip route`** | `Quản lý bảng tuyến đường Routing Table` | show, add, del | `ip route add default via 192.168.1.1` |
| **`ip neighbor`** | `Xem và xóa bảng ARP Cache chứa địa chỉ MAC` | show, flush | `ip neighbor show` |


---

## 4. 🛠 Thao Tác Thực Chiến & Kịch Bản DevOps (Real-World Scenarios)

### 🛠 Các lệnh thực hành & Cấu hình chuẩn Production:
```bash
# 1. Thêm IP phụ cho Card mạng:
sudo ip addr add 10.0.0.100/24 dev eth0

# 2. Thêm Static Route tới mạng nộ bộ VPC khác:
sudo ip route add 172.16.0.0/12 via 10.0.0.1 dev eth0

# 3. Xem bảng ARP Cache:
ip neighbor show
```

### 🚀 Kịch bản xử lý sự cố thực tế khi đi làm:
Debug máy chủ bị mất kết nối ra ngoài Internet do đè sai Default Gateway:
ip route show
# Fix: Xóa gateway sai và thêm gateway đúng:
sudo ip route del default
sudo ip route add default via 192.168.1.1 dev eth0

## 5. 🚀 Bộ Câu Hỏi Phỏng Vấn DevOps & SysAdmin Thực Tế (Interview Q&A)

> **Q: Lệnh hiện đại nào thay thế hoàn toàn lệnh `route -n` để xem bảng tuyến đường trên Linux?**  
> **A**: Lệnh `ip route` (hoặc `ip route show`).

> **Q: Làm sao thêm một địa chỉ IP phụ (Secondary IP) vào card mạng `eth0` bằng lệnh `ip`?**  
> **A**: Dùng lệnh `sudo ip addr add 10.0.0.100/24 dev eth0`.
