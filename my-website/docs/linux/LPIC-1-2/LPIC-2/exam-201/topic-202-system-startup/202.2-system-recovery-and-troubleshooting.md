## 1. 🧠 Hình Hình Dung Nhanh (Intuitive Mindset)

Cứu hộ Linux giống như thợ khóa mở cửa khẩn cấp: Khi hệ thống hỏng không lên màn hình đăng nhập, dùng đĩa Live USB boot vào, chroot biến thư mục đĩa cứng thành root thật để sửa file lỗi.

## 2. 📚 Lý Thuyết Chuyên Sâu & Bản Chất Hệ Thống (Under The Hood Mechanics - LPIC-2 Official Study Guide)

### 2.1 Kịch Bản Cứu Hộ Máy Chủ Linux (Recovery Procedures)
1. **Vào Rescue / Emergency Target trong Systemd**:
   - Boot GRUB2 -> Bấm `e` -> Thêm `systemd.unit=rescue.target` (hoặc `emergency.target`) vào cuối dòng Kernel -> `Ctrl+X`.
2. **Quy Trình Cứu Hộ Qua Live ISO bằng `chroot`**:
   - Khi máy chủ bị hỏng hoàn toàn Kernel/GRUB:
     1. Boot bằng đĩa Ubuntu/RHEL Live ISO.
     2. Mount đĩa cứng bị hỏng vào `/mnt`: `sudo mount /dev/sda1 /mnt`.
     3. Mount các thư mục ảo hệ thống:
        `sudo mount --bind /dev /mnt/dev`  
        `sudo mount --bind /proc /mnt/proc`  
        `sudo mount --bind /sys /mnt/sys`
     4. Chuyển quyền vào đĩa cứng hỏng: `sudo chroot /mnt`.
     5. Cài lại GRUB hoặc khôi phục mật khẩu: `grub-install /dev/sda && update-grub`.
     6. Exit chroot, unmount và reboot.
3. **Xử Lý Sự Cố Lỗi `/etc/fstab` Làm Máy Bị Khóa Boot**:
   - Khi mount sai UUID trong `/etc/fstab`, Systemd dừng tại Emergency mode và mount ổ đĩa `/` dưới dạng Read-Only.
   - Sửa lỗi: Remount đĩa root dạng Read-Write: `mount -o remount,rw /` rồi dùng Vim sửa lại `/etc/fstab`.

## 4. 🛠 Thao Tác Thực Chiến & Kịch Bản DevOps (Real-World Scenarios)

### 🛠 Các lệnh thực hành & Cấu hình chuẩn Production:
```bash
# Quy trình chroot cứu hộ hệ thống từ Live ISO:
sudo mount /dev/sda1 /mnt
for i in /dev /dev/pts /proc /sys /run; do sudo mount -B $i /mnt$i; done
sudo chroot /mnt
grub-install /dev/sda
update-grub
exit
```

### 🚀 Kịch bản xử lý sự cố thực tế khi đi làm:
Sửa lỗi treo boot do sai file /etc/fstab:
mount -o remount,rw /
vim /etc/fstab
reboot

## 5. 🚀 Bộ Câu Hỏi Phỏng Vấn DevOps & SysAdmin Thực Tế (Interview Q&A)

> **Q: Khi /etc/fstab bị lỗi làm hệ thống dừng ở Emergency mode dạng Read-Only, lệnh nào giúp mở quyền ghi để sửa file?**  
> **A**: Lệnh `mount -o remount,rw /`.

> **Q: Lệnh nào biến một thư mục mount đĩa từ Live ISO thành thư mục Root của hệ thống?**  
> **A**: Lệnh `chroot /mnt`.
