---

## 1. 🧠 Hình Hình Dung Nhanh (Intuitive Mindset)

Full Backup = Chụp ảnh toàn bộ ngôi nhà. Incremental Backup = Chỉ chụp lại những đồ đạc MỚI MUA thêm so với ngày hôm qua. Differential Backup = Chụp lại toàn bộ đồ đạc mới mua tính từ ngày Full Backup gần nhất.

---

## 2. 📚 Lý Thuyết Chuyên Sâu & Bản Chất Hệ Thống (Under The Hood Mechanics - LPIC-2 Official Study Guide)

### 2.1 Bản Chất Các Chiến Lược Backup

| Loại Backup | Khái niệm | Tốc độ Backup | Dung lượng tốn | Tốc độ Restore |
| :--- | :--- | :--- | :--- | :--- |
| **Full Backup** | Sao lưu TOÀN BỘ dữ liệu hệ thống | Chậm nhất | Tốn nhất | Nhanh nhất (Chỉ cần 1 bản) |
| **Incremental (Lũy tiến)**| Chỉ sao lưu dữ liệu thay đổi so với bản **Backup gần nhất** | Nhanh nhất | Tiết kiệm nhất | Chậm (Cần bản Full + Tất cả bản Incremental) |
| **Differential (Khác biệt)**| Sao lưu dữ liệu thay đổi so với bản **Full Backup gần nhất** | Trung bình | Trung bình | Nhanh (Chỉ cần bản Full + 1 bản Differential mới nhất) |

---

### 2.2 Công Cụ Đồng Bộ Dữ Liệu Thần Thánh `rsync`
- `rsync` sử dụng thuật toán **Delta Transfer Algorithm**: Chỉ truyền đi những phần dữ liệu bị thay đổi trong file thay vì truyền lại toàn bộ file!
- Tham số chuẩn DevOps: `rsync -avz --delete /src/ user@remote:/dst/`.

## 3. ⚡ Bảng Tra Cứu Câu Lệnh & Cấu Hình Thực Hành (CLI Reference)

| Câu lệnh / Component | Tham số / Option | Giải thích ý nghĩa chi tiết | Ví dụ thực tế trong DevOps / SysAdmin |
| :--- | :--- | :--- | :--- |
| **`rsync`** | `Đồng bộ dữ liệu thông minh cục bộ hoặc qua SSH` | -avz, --delete | `rsync -avz /data/ backup:/data/` |
| **`cpio`** | `Công cụ lưu trữ gom file dạng luồng stream` | -o, -i, -p | `find . | cpio -o > archive.cpio` |
| **`dd`** | `Sao lưu đĩa cứng cấp độ Block (Bit-by-bit copy)` | if, of, bs | `dd if=/dev/sda of=/backup/sda.img bs=4M status=progress` |

## 4. 🛠 Thao Tác Thực Chiến & Kịch Bản DevOps (Real-World Scenarios)

### 🛠 Các lệnh thực hành & Cấu hình chuẩn Production:
```bash
# Script đồng bộ backup dữ liệu sang Backup Server qua SSH:
rsync -avz -e 'ssh -p 2222' --delete /var/www/html/ backup-user@10.0.0.50:/backups/www/
```

### 🚀 Kịch bản xử lý sự cố thực tế khi đi làm:
Tạo bản sao đĩa cứng MBR cấp độ block bằng dd:
sudo dd if=/dev/sda of=/mnt/external/sda_backup.img bs=4M status=progress

## 5. 🚀 Bộ Câu Hỏi Phỏng Vấn DevOps & SysAdmin Thực Tế (Interview Q&A)

> **Q: Sự khác biệt về cách Restore giữa Incremental Backup và Differential Backup là gì?**  
> **A**: Incremental cần bản Full + TOÀN BỘ các bản Incremental theo thứ tự. Differential chỉ cần bản Full + BẢN DIFFERENTIAL MỚI NHẤT.

> **Q: Tại sao `rsync` lại truyền dữ liệu qua mạng nhanh hơn nhiều so với `scp` hay `cp`?**  
> **A**: Vì `rsync` sử dụng thuật toán Delta Transfer, chỉ truyền những byte dữ liệu bị thay đổi bên trong file chứ không truyền lại cả file.
