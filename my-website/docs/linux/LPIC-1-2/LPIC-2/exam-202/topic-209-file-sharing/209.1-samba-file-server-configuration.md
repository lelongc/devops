## 2. 📚 Lý Thuyết Chuyên Sâu & Bản Chất Hệ Thống (Under The Hood Mechanics - LPIC-2 Official Study Guide)

### 2.1 Cấu Trúc Quản Trị Máy Chủ Samba Server
1. **Kiến Trúc Cấu Hình File `/etc/samba/smb.conf`**:
   - **Khối `[global]`**: Cấu hình tên Workgroup/Domain, cơ chế authen (`security = user`).
   - **Khối Share `[share_name]`**: Phân quyền thư mục chia sẻ.
```ini
[global]
    workgroup = WORKGROUP
    server string = DevOps Samba Storage
    security = user
    map to guest = Bad User

[data_share]
    path = /srv/samba/data
    read only = no
    browsable = yes
    valid users = @devops_group
    create mask = 0664
    directory mask = 0775
```
2. **Cơ Cơ Quản Lý User Trong Samba (`smbpasswd`)**:
   - Tài khoản hệ thống Linux BẮT BUỘC phải tồn tại trước khi tạo Samba user: `sudo smbpasswd -a username`.

## 3. ⚡ Bảng Tra Cứu Câu Lệnh & Cấu Hình Thực Hành (CLI Reference)

| Câu lệnh / Component | Tham số / Option | Giải thích ý nghĩa chi tiết | Ví dụ thực tế trong DevOps / SysAdmin |
| :--- | :--- | :--- | :--- |
| **`testparm`** | `Kiểm tra cú pháp file cấu hình /etc/samba/smb.conf` | Không | `testparm` |
| **`smbpasswd`** | `Tạo và đổi mật khẩu tài khoản truy cập Samba` | -a, -x, -d | `sudo smbpasswd -a devops` |
| **`smbclient`** | `Công cụ CLI truy vấn và duyệt thư mục Samba từ xa` | -L, -U | `smbclient -L //10.0.0.10 -U devops` |
| **`mount -t cifs`** | `Mount thư mục chia sẻ Samba/CIFS vào cây thư mục Linux` | -o username=X | `sudo mount -t cifs //10.0.0.10/data /mnt/samba -o username=devops` |

## 4. 🛠 Thao Tác Thực Chiến & Kịch Bản DevOps (Real-World Scenarios)

### 🛠 Các lệnh thực hành & Cấu hình chuẩn Production:
```bash
# 1. Tạo thư mục chia sẻ và cấp quyền cho Samba:
sudo mkdir -p /srv/samba/data
sudo chown -R root:devops_group /srv/samba/data
sudo chmod -R 775 /srv/samba/data

# 2. Tạo User Samba và kiểm tra config:
sudo smbpasswd -a devops_user
testparm
sudo systemctl restart smbd
```

### 🚀 Kịch bản xử lý sự cố thực tế khi đi làm:
Mount ổ đĩa chia sẻ Samba Windows sang Linux Server tự động qua /etc/fstab:
//192.168.1.10/shared  /mnt/win_share  cifs  credentials=/etc/samba/credentials,iocharset=utf8  0  0

## 5. 🚀 Bộ Câu Hỏi Phỏng Vấn DevOps & SysAdmin Thực Tế (Interview Q&A)

> **Q: Tại sao lệnh `smbpasswd -a username` báo lỗi nếu user đó chưa tồn tại trên hệ thống Linux?**  
> **A**: Vì Samba yêu cầu User phải tồn tại trong `/etc/passwd` của hệ thống Linux trước khi được thêm vào cơ sở dữ liệu passdb của Samba.

> **Q: Lệnh nào kiểm tra lỗi cú pháp file cấu hình `smb.conf`?**  
> **A**: Lệnh `testparm`.
