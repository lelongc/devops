> 💡 **Bản chất 1 câu**: Chia sẻ đĩa cứng tốc độ cao giữa các máy chủ Linux với Network File System (NFSv3/NFSv4), cấu hình `/etc/exports`, `exportfs` và mount NFS.  
> 🎯 **Trọng tâm phỏng vấn Senior DevOps / SysAdmin**: NFS Server (nfs-kernel-server, nfs-server), file /etc/exports, exportfs (-a, -r, -v), showmount -e, rpcbind, mount options (nfsvers=4, rw, sync, no_root_squash, root_squash).

## 1. 🧠 Hình Hình Dung Nhanh (Intuitive Mindset)

NFS như ổ đĩa dùng chung cắm qua cáp mạng LAN: Giúp hàng trăm Kubernetes Worker Nodes hoặc Web Servers cùng truy cập chung một thư mục ổ đĩa `/var/www/uploads` với tốc độ cực nhanh.

## 2. 📚 Lý Thuyết Chuyên Sâu & Bản Chất Hệ Thống (Under The Hood Mechanics - LPIC-2 Official Study Guide)

### 2.1 Cấu Trúc Quản Trị Máy Chủ Chia Sẻ File NFS
1. **Kiến Trúc So Sánh NFSv3 vs NFSv4**:
   - **NFSv3**: Phụ thuộc dịch vụ `rpcbind` (Portmap) mở nhiều cổng ngẫu nhiên.
   - **NFSv4**: Chỉ sử dụng **MỘT cổng duy nhất 2049 TCP**, hỗ trợ xác thực Kerberos.
2. **Cấu Hình File Chia Sẻ `/etc/exports`**:
   - `/path/to/export  client_IP(options)`
   - Options: `rw`, `sync`, `root_squash` (biến root client thành nobody), `no_root_squash` (giữ quyền root client).
3. **Cập Nhật Cấu Hình Không Cần Restart Dịch Vụ (`exportfs`)**:
   - `sudo exportfs -ra`: Nạp lại toàn bộ file `/etc/exports` tức thì.

## 3. ⚡ Bảng Tra Cứu Câu Lệnh & Cấu Hình Thực Hành (CLI Reference)

| Câu lệnh / Component | Tham số / Option | Giải thích ý nghĩa chi tiết | Ví dụ thực tế trong DevOps / SysAdmin |
| :--- | :--- | :--- | :--- |
| **`exportfs`** | `Quản lý và nạp lại danh sách thư mục chia sẻ NFS` | -a, -r, -v | `sudo exportfs -ra` |
| **`showmount`** | `Xem danh sách các thư mục NFS share từ xa của Server` | -e IP | `showmount -e 10.0.0.10` |

## 4. 🛠 Thao Tác Thực Chiến & Kịch Bản DevOps (Real-World Scenarios)

### 🛠 Các lệnh thực hành & Cấu hình chuẩn Production:
```bash
# 1. Cấu hình /etc/exports cho Kubernetes Storage Cluster:
/srv/nfs/k8s_data  10.0.0.0/24(rw,sync,no_root_squash,no_subtree_check)

# 2. Apply cấu hình và kiểm tra:
sudo exportfs -ra
showmount -e localhost
```

### 🚀 Kịch bản xử lý sự cố thực tế khi đi làm:
Mount ổ đĩa NFS v4 trên máy Web Client:
sudo mount -t nfs -o nfsvers=4,noatime 10.0.0.10:/srv/nfs/k8s_data /var/www/uploads

## 5. 🚀 Bộ Câu Hỏi Phỏng Vấn DevOps & SysAdmin Thực Tế (Interview Q&A)

> **Q: Tùy chọn `root_squash` trong `/etc/exports` mang lại lợi ích bảo mật gì?**  
> **A**: `root_squash` chuyển đổi quyền `root` từ máy client thành user vô danh `nobody`, ngăn Hacker chiếm root trên máy client xóa sạch dữ liệu trên NFS Server.

> **Q: Lệnh nào nạp lại cấu hình file `/etc/exports` lập tức mà không cần ngắt dịch vụ NFS?**  
> **A**: Lệnh `sudo exportfs -ra`.
