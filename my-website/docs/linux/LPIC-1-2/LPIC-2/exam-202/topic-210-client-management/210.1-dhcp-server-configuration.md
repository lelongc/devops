## 1. 🧠 Hình Hình Dung Nhanh (Intuitive Mindset)

DHCP Server như nhân viên lễ tân phát thẻ phòng tự động: Khi máy tính cắm dây mạng vào LAN, DHCP Server tự cấp địa chỉ IP, Subnet Mask, Gateway và DNS Server để máy lên mạng ngay.

## 2. 📚 Lý Thuyết Chuyên Sâu & Bản Chất Hệ Thống (Under The Hood Mechanics - LPIC-2 Official Study Guide)

### 2.1 Bản Chất Tiến Trình Cấp IP DORA & Cấu Hình DHCP
1. **Tiến Trình 4 Bước DORA (DHCP Handshake)**:
   - **D - Discover**: Client phát gói Broadcast tìm DHCP Server.
   - **O - Offer**: DHCP Server gửi phản hồi đề xuất địa chỉ IP.
   - **R - Request**: Client gửi yêu cầu chấp nhận thuê IP đó.
   - **A - Acknowledge**: DHCP Server gửi xác nhận chốt hợp đồng thuê.
2. **Cấu Hình File `/etc/dhcp/dhcpd.conf`**:
```dhcpd
subnet 10.0.0.0 netmask 255.255.255.0 {
    range 10.0.0.100 10.0.0.200;
    option routers 10.0.0.1;
    option domain-name-servers 8.8.8.8, 1.1.1.1;
}

host printer_office {
    hardware ethernet 00:11:22:33:44:55;
    fixed-address 10.0.0.50;
}
```

## 5. 🚀 Bộ Câu Hỏi Phỏng Vấn DevOps & SysAdmin Thực Tế (Interview Q&A)

> **Q: Viết tắt DORA trong giao thức cấp phát DHCP đại diện cho 4 bước nào?**  
> **A**: Represent cho **Discover, Offer, Request, Acknowledge**.

> **Q: Công cụ nào giúp chuyển tiếp gói tin DHCP Broadcast từ Subnet này sang máy chủ DHCP Server nằm ở Subnet khác?**  
> **A**: Công cụ **DHCP Relay Agent (`dhcrelay`)**.
