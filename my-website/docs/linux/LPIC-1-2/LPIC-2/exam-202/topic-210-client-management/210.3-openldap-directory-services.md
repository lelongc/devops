## 1. 🧠 Hình Hình Dung Nhanh (Intuitive Mindset)

OpenLDAP như cuốn danh bạ điện thoại hình cây của tập đoàn: Thay vì phải tạo 100 tài khoản user trên 100 Server Linux lẻ tẻ, bạn lưu tất cả user trên OpenLDAP Server để mọi máy chủ cùng xác thực tập trung về một nơi.

## 2. 📚 Lý Thuyết Chuyên Sâu & Bản Chất Hệ Thống (Under The Hood Mechanics - LPIC-2 Official Study Guide)

### 2.1 Kiến Trúc Cây DIT & Các Thuộc Tính OpenLDAP
1. **Cấu Trúc Cây Thư Mục DIT (Directory Information Tree)**:
   - **DN (Distinguished Name)**: Địa chỉ định danh tuyệt đối duy nhất (`dn: cn=John,ou=Users,dc=company,dc=com`).
   - `dc`: Domain Component (`dc=company,dc=com`).
   - `ou`: Organizational Unit (`ou=DevOps`).
   - `cn`: Common Name (`cn=John Doe`).
   - `uid`: User ID (`uid=johndoe`).
2. **Các Công Cụ Truy Vấn & Thao Tác LDAP**:
   - `ldapsearch -x -b "dc=company,dc=com" "(uid=johndoe)"`: Tìm kiếm thông tin user.
   - `ldapadd -x -D "cn=admin,dc=company,dc=com" -W -f new_user.ldif`: Thêm user từ file LDIF.

## 3. ⚡ Bảng Tra Cứu Câu Lệnh & Cấu Hình Thực Hành (CLI Reference)

| Câu lệnh / Component | Tham số / Option | Giải thích ý nghĩa chi tiết | Ví dụ thực tế trong DevOps / SysAdmin |
| :--- | :--- | :--- | :--- |
| **`ldapsearch`** | `Truy vấn và tìm kiếm dữ liệu trong máy chủ OpenLDAP` | -x, -b, -D, -W | `ldapsearch -x -b 'dc=company,dc=com' '(objectClass=*)'` |
| **`ldapadd`** | `Thêm đối tượng mới từ file LDIF vào LDAP` | -x, -D, -W, -f | `ldapadd -x -D 'cn=admin,dc=company,dc=com' -W -f user.ldif` |
| **`slapcat`** | `Xuất toàn bộ cơ sở dữ liệu LDAP sang dạng text LDIF` | -l output.ldif | `sudo slapcat -l backup.ldif` |

## 4. 🛠 Thao Tác Thực Chiến & Kịch Bản DevOps (Real-World Scenarios)

### 🛠 Các lệnh thực hành & Cấu hình chuẩn Production:
```bash
# Tìm kiếm tất cả User thuộc phòng ban DevOps trong LDAP:
ldapsearch -x -H ldap://10.0.0.10 -b "ou=DevOps,dc=company,dc=com" "(objectClass=posixAccount)"
```

### 🚀 Kịch bản xử lý sự cố thực tế khi đi làm:
Sao lưu dự phòng toàn bộ cơ sở dữ liệu OpenLDAP:
sudo slapcat -l /backups/ldap_$(date +%F).ldif

## 5. 🚀 Bộ Câu Hỏi Phỏng Vấn DevOps & SysAdmin Thực Tế (Interview Q&A)

> **Q: DN (`Distinguished Name`) trong OpenLDAP đóng vai trò gì?**  
> **A**: DN là địa chỉ định danh tuyệt đối duy nhất đại diện cho mốc vị trí của một đối tượng trong cây thư mục DIT.

> **Q: Lệnh nào xuất toàn bộ cơ sở dữ liệu OpenLDAP trực tiếp từ file đĩa sang định dạng văn bản LDIF để backup?**  
> **A**: Lệnh `sudo slapcat -l backup.ldif`.
