## 1. 🧠 Hình Hình Dung Nhanh (Intuitive Mindset)

Security Audit & Fail2ban như hệ thống camera và bảo vệ tự động: Nmap quét tìm cửa hở, RKHunter rà soát xem có kẻ gian nấp dưới gầm giường không, còn Fail2ban thấy kẻ nào cố tình dò khóa 5 lần là lập tức trói tay ném ra ngoài (Block IP).

---

## 2. 📚 Lý Thuyết Chuyên Sâu & Bản Chất Hệ Thống (Under The Hood Mechanics - LPIC-2 Official Study Guide)

### 2.1 Bộ Công Cụ Security Audit & Intrusion Detection
1. **nmap**: `nmap -sV -p 1-65535 10.0.0.10` quét port mở và tên phiên bản dịch vụ.
2. **rkhunter & chkrootkit**: So sánh SHA-1 hash của file binary hệ thống để phát hiện Rootkit chèn backdoor.
3. **Fail2ban**: Đọc file log, tự động gọi IPTables DROP IP gõ sai mật khẩu quá số lần `maxretry`.

## 3. ⚡ Bảng Tra Cứu Câu Lệnh & Cấu Hình Thực Hành (CLI Reference)

| Câu lệnh / Component | Tham số / Option | Giải thích ý nghĩa chi tiết | Ví dụ thực tế trong DevOps / SysAdmin |
| :--- | :--- | :--- | :--- |
| **`fail2ban-client`** | `Quản lý và kiểm tra danh sách IP bị Fail2ban ban` | status, set unbanip | `sudo fail2ban-client status sshd` |

## 4. 🛠 Thao Tác Thực Chiến & Kịch Bản DevOps (Real-World Scenarios)

### 🛠 Các lệnh thực hành & Cấu hình chuẩn Production:
```bash
# 1. Kiểm tra danh sách các IP đang bị Fail2ban chặn ở jail sshd:
sudo fail2ban-client status sshd

# 2. Gỡ ban cho IP của đồng nghiệp lỡ gõ sai pass:
sudo fail2ban-client set sshd unbanip 192.168.1.100

# 3. Quét kiểm tra Rootkit hệ thống:
sudo rkhunter --check --sk
```

### 🚀 Kịch bản xử lý sự cố thực tế khi đi làm:
Bảo vệ máy chủ SSH khỏi các đợt tấn công Brute-force tự động từ Botnet:
sudo apt install -y fail2ban
sudo cp /etc/fail2ban/jail.conf /etc/fail2ban/jail.local
sudo systemctl enable --now fail2ban

## 5. 🚀 Bộ Câu Hỏi Phỏng Vấn DevOps & SysAdmin Thực Tế (Interview Q&A)

> **Q: Cơ chế hoạt động của `Fail2ban` giúp bảo vệ Server khỏi tấn công Brute-force như thế nào?**  
> **A**: Fail2ban liên tục đọc log dịch vụ, nếu phát hiện IP gõ sai pass quá số lần `maxretry`, nó tự động gọi `iptables` để DROP IP đó.

> **Q: Lệnh nào mở khóa (Unban) cho một địa chỉ IP bị Fail2ban chặn nhầm?**  
> **A**: Lệnh `sudo fail2ban-client set <jail_name> unbanip <IP_Address>`.
