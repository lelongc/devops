## 2. 📚 Lý Thuyết Chuyên Sâu & Bản Chất Hệ Thống (Under The Hood Mechanics - LPIC-2 Official Study Guide)

### 2.1 OpenVPN vs WireGuard vs IPsec
1. **WireGuard (Chuẩn VPN Kernel Space Thế Hệ Mới)**:
   - Tích hợp trực tiếp vào Kernel Linux (Kernel 5.6+). Sử dụng thuật toán ChaCha20, Poly1305.
   - Cực kỳ gọn nhẹ (~4,000 dòng code), tốc độ siêu nhanh, độ trễ cực thấp.
2. **OpenVPN**:
   - Chạy ở User Space qua thiết bị ảo `tun/tap`. Cấu hình linh hoạt nhưng tốc độ chậm hơn WireGuard.

## 3. ⚡ Bảng Tra Cứu Câu Lệnh & Cấu Hình Thực Hành (CLI Reference)

| Câu lệnh / Component | Tham số / Option | Giải thích ý nghĩa chi tiết | Ví dụ thực tế trong DevOps / SysAdmin |
| :--- | :--- | :--- | :--- |
| **`wg-quick`** | `Khởi động hoặc ngắt mạng VPN WireGuard nhanh chóng` | up, down | `sudo wg-quick up wg0` |
| **`wg`** | `Kiểm tra trạng thái kết nối và lưu lượng VPN WireGuard` | show | `sudo wg show` |
| **`openvpn`** | `Chạy dịch vụ VPN OpenVPN với file cấu hình` | --config file | `sudo openvpn --config client.ovpn` |

## 4. 🛠 Thao Tác Thực Chiến & Kịch Bản DevOps (Real-World Scenarios)

### 🛠 Các lệnh thực hành & Cấu hình chuẩn Production:
```bash
# 1. Tạo cặp khóa WireGuard cho Server:
wg genkey | tee server_private.key | wg pubkey > server_public.key

# 2. Bật interface WireGuard wg0:
sudo wg-quick up wg0
sudo wg show
```

### 🚀 Kịch bản xử lý sự cố thực tế khi đi làm:
Tạo VPN Tunnel bảo mật nối 2 Datacenter bằng WireGuard:
sudo wg show wg0

## 5. 🚀 Bộ Câu Hỏi Phỏng Vấn DevOps & SysAdmin Thực Tế (Interview Q&A)

> **Q: Tại sao WireGuard đạt tốc độ truyền tải dữ liệu VPN nhanh hơn hẳn so me với OpenVPN?**  
> **A**: Vì WireGuard chạy trực tiếp trong **Kernel Space** và sử dụng mã nguồn cực kỳ gọn nhẹ cùng thuật toán mã hóa ChaCha20 mới.

> **Q: Lệnh nào xem trạng thái các Peer đang kết nối và dung lượng dữ liệu truyền qua WireGuard?**  
> **A**: Lệnh `sudo wg show`.
