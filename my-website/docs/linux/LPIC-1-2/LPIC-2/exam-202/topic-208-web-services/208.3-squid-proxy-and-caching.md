# 🐧 Objective 208.3: Quản Trị Máy Chủ Proxy & Caching Squid - Bản Chất Hệ Thống LPIC-2 & Thực Chiến DevOps

> 💡 **Bản chất 1 câu**: Triển khai Squid Proxy Server (`squid.conf`), phân quyền kiểm soát truy cập Access Control Lists (ACLs), Transparent Proxy và Caching.  
> 🎯 **Trọng tâm phỏng vấn Senior DevOps / SysAdmin**: Squid config (/etc/squid/squid.conf), acl (src, dstdomain, port), http_access (allow/deny), cache_dir, transparent / intercept proxy, squid -k reconfigure.

---

## 1. 🧠 Hình Hình Dung Nhanh (Intuitive Mindset)

Squid Proxy như mộc cửa kiểm soát an ninh công ty: Mọi nhân viên muốn truy cập Internet phải đi qua Squid. Squid kiểm tra xem website có bị cấm không (chặn Facebook/Youtube), nếu hợp lệ thì tải về và lưu bản sao (Cache) để người sau truy cập không tốn băng thông.

---

## 2. 📚 Lý Thuyết Chuyên Sâu & Bản Chất Hệ Thống (Under The Hood Mechanics - LPIC-2 Official Study Guide)

### 2.1 Cấu Trúc Quản Lý Máy Chủ Proxy Squid
1. **Kiến Trúc ACLs (Access Control Lists) & Rules**:
   - Squid kiểm tra quy tắc từ TRÊN XUỐNG DƯỚI. Quy tắc nào khớp trước sẽ được áp dụng ngay.
   - Định nghĩa ACL: `acl ACL_NAME TYPE value`.
     - `acl localnet src 10.0.0.0/8`
     - `acl blocked_sites dstdomain .facebook.com .tiktok.com`
   - Áp dụng Rule: `http_access deny blocked_sites` và `http_access allow localnet`.
2. **Transparent / Intercept Proxy**:
   - Mọi traffic HTTP Port 80 được Firewall Router tự động chuyển hướng (DNAT) sang cổng Squid Port 3128.

## 4. 🛠 Thao Tác Thực Chiến & Kịch Bản DevOps (Real-World Scenarios)

### 🛠 Các lệnh thực hành & Cấu hình chuẩn Production:
```bash
# Cấu hình chặn web rác và mở cache trong /etc/squid/squid.conf:
acl internal_network src 192.168.1.0/24
acl bad_domains dstdomain "/etc/squid/bad_domains.txt"

http_access deny bad_domains
http_access allow internal_network
http_access deny all

cache_dir ufs /var/spool/squid 10000 16 256
```

### 🚀 Kịch bản xử lý sự cố thực tế khi đi làm:
Kiểm tra cú pháp và áp dụng cấu hình Squid:
sudo squid -k parse && sudo squid -k reconfigure

## 5. 🚀 Bộ Câu Hỏi Phỏng Vấn DevOps & SysAdmin Thực Tế (Interview Q&A)

> **Q: Thứ tự áp dụng quy tắc `http_access` trong Squid Proxy diễn ra như thế nào?**  
> **A**: Kiểm tra từ trên xuống dưới theo thứ tự xuất hiện trong file `squid.conf`. Quy tắc nào khớp trước sẽ được thực thi ngay lập tức.

> **Q: Lệnh nào nạp lại cấu hình Squid mà không làm ngắt các kết nối proxy hiện tại?**  
> **A**: Lệnh `sudo squid -k reconfigure`.
