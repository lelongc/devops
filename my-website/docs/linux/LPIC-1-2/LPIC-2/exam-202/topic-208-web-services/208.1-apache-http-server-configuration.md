# 🐧 Objective 208.1: Quản Trị Máy Chủ Web Apache HTTP Server - Bản Chất Hệ Thống LPIC-2 & Thực Chiến DevOps

> 💡 **Bản chất 1 câu**: Cấu hình Apache HTTP Server (`httpd.conf`/`apache2.conf`), VirtualHosts, phân quyền `.htaccess`, module `mod_ssl` và `mod_rewrite`.  
> 🎯 **Trọng tâm phỏng vấn Senior DevOps / SysAdmin**: Apache config (/etc/httpd/conf/httpd.conf, /etc/apache2/sites-available/), VirtualHost, .htaccess (AllowOverride), mod_ssl, mod_rewrite, apachectl / apache2ctl.

---

## 1. 🧠 Hình Hình Dung Nhanh (Intuitive Mindset)

Apache Web Server như một tòa nhà văn phòng cho thuê: Mỗi VirtualHost là một gian phòng dành cho một website riêng (domain1.com, domain2.com) chạy chung trên 1 máy chủ.

---

## 2. 📚 Lý Thuyết Chuyên Sâu & Bản Chất Hệ Thống (Under The Hood Mechanics - LPIC-2 Official Study Guide)

### 2.1 Cấu Trúc Quản Trị Máy Chủ Web Apache
1. **Kiến Trúc Cấu Hình Trên RHEL vs Ubuntu**:
   - **RHEL / CentOS**: File cấu hình chính `/etc/httpd/conf/httpd.conf`.
   - **Debian / Ubuntu**: File chính `/etc/apache2/apache2.conf`. Quản lý VirtualHosts qua `/etc/apache2/sites-available/` và symlink sang `sites-enabled/` qua lệnh `a2ensite` / `a2dissite`.
2. **Cấu Hình VirtualHost Tối Ưu chuẩn SSL**:
```apache
<VirtualHost *:443>
    ServerName app.company.com
    DocumentRoot /var/www/app
    SSLEngine on
    SSLCertificateFile /etc/ssl/certs/app.crt
    SSLCertificateKeyFile /etc/ssl/private/app.key

    <Directory /var/www/app>
        AllowOverride All
        Require all granted
    </Directory>
</VirtualHost>
```
3. **Phân Quyền Thư Mục `.htaccess` & `AllowOverride`**:
   - `.htaccess` cho phép lập trình viên tự cấu hình rewrite URL. BẮT BUỘC đặt `AllowOverride All` trong khối `<Directory>` để kích hoạt.

## 3. ⚡ Bảng Tra Cứu Câu Lệnh & Cấu Hình Thực Hành (CLI Reference)

| Câu lệnh / Component | Tham số / Option | Giải thích ý nghĩa chi tiết | Ví dụ thực tế trong DevOps / SysAdmin |
| :--- | :--- | :--- | :--- |
| **`apache2ctl / apachectl`** | `Công cụ kiểm tra cú pháp và điều khiển Apache` | configtest, graceful | `sudo apache2ctl configtest` |
| **`a2ensite / a2dissite`** | `Bật hoặc tắt một VirtualHost site trên Ubuntu` | site_name | `sudo a2ensite app.conf` |
| **`a2enmod`** | `Bật một module Apache (như rewrite, ssl, proxy)` | module_name | `sudo a2enmod rewrite ssl` |

## 4. 🛠 Thao Tác Thực Chiến & Kịch Bản DevOps (Real-World Scenarios)

### 🛠 Các lệnh thực hành & Cấu hình chuẩn Production:
```bash
# 1. Bật module SSL và Rewrite trên Ubuntu:
sudo a2enmod ssl rewrite proxy_http

# 2. Kiểm tra cú pháp cấu hình Apache trước khi reload:
sudo apache2ctl configtest
sudo systemctl reload apache2
```

### 🚀 Kịch bản xử lý sự cố thực tế khi đi làm:
Debug lỗi Apache không nạp file .htaccess:
# Mở file config VirtualHost và đảm bảo đổi 'AllowOverride None' thành 'AllowOverride All'

## 5. 🚀 Bộ Câu Hỏi Phỏng Vấn DevOps & SysAdmin Thực Tế (Interview Q&A)

> **Q: Lệnh nào kiểm tra cú pháp cấu hình Apache trước khi reload dịch vụ?**  
> **A**: Lệnh `sudo apache2ctl configtest` (hoặc `httpd -t`).

> **Q: Chỉ thị nào trong khối `<Directory>` quyết định việc file `.htaccess` có được phép hoạt động hay không?**  
> **A**: Chỉ thị `AllowOverride All` (nếu đặt `None` thì `.htaccess` bị vô hiệu hóa).
