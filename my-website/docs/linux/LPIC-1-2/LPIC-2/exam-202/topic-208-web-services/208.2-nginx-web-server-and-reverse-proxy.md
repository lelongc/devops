## 1. 🧠 Hình Hình Dung Nhanh (Intuitive Mindset)

Nginx Reverse Proxy như người lễ tân khách sạn 5 sao: Toàn bộ truy cập của khách từ bên ngoài Internet đều gặp Nginx. Nginx kiểm tra SSL, nén dữ liệu rồi điều phối request về các Server backend phía sau xử lý.

## 2. 📚 Lý Thuyết Chuyên Sâu & Bản Chất Hệ Thống (Under The Hood Mechanics - LPIC-2 Official Study Guide)

### 2.1 Kiến Trúc Event-Driven Của Nginx & Cấu Hình Reverse Proxy
1. **Ưu Điểm Kiến Trúc Event-Driven (Asynchronous)**:
   - Nginx dùng kiến trúc bất đồng bộ Master-Worker Process kết hợp syscall `epoll`. 1 Worker process của Nginx có thể xử lý hàng chục nghìn kết nối đồng thời với bộ nhớ RAM cực thấp.
2. **Cấu Hình Reverse Proxy & Load Balancer (`upstream`)**:
```nginx
upstream backend_app {
    least_conn; # Thuật toán điều phối: ít connection nhất
    server 10.0.0.10:8080 max_fails=3 fail_timeout=10s;
    server 10.0.0.11:8080 max_fails=3 fail_timeout=10s;
}

server {
    listen 443 ssl http2;
    server_name app.company.com;

    ssl_certificate /etc/letsencrypt/live/app.company.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/app.company.com/privkey.pem;

    location / {
        proxy_pass http://backend_app;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

    location ~ \.php$ {
        fastcgi_pass unix:/run/php/php8.2-fpm.sock;
        include fastcgi_params;
        fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name;
    }
}
```

## 5. 🚀 Bộ Câu Hỏi Phỏng Vấn DevOps & SysAdmin Thực Tế (Interview Q&A)

> **Q: Lỗi `502 Bad Gateway` trên Nginx Reverse Proxy thường chỉ ra nguyên nhân gì?**  
> **A**: Chỉ ra Nginx không thể kết nối tới máy chủ Backend/PHP-FPM phía sau (backend bị sập, sai IP/Port hoặc hỏng file UNIX Socket).

> **Q: Thuật toán Load Balancing nào trong Nginx giúp gắn cố định IP của User vào đúng 1 Backend Server (Session Persistence)?**  
> **A**: Thuật toán `ip_hash;`.
