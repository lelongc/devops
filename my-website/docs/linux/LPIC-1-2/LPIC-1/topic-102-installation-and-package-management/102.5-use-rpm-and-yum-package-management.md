# 🐧 Objective 102.5: Trình Quản Lý Gói Red Hat (RPM & DNF/YUM) - Bản Chất Hệ Thống & Thực Chiến DevOps

> 💡 **Bản chất 1 câu**: Quản lý gói trên RHEL/CentOS/Rocky Linux: `rpm` thao tác gói `.rpm` cục bộ, `dnf/yum` tải tự động từ `/etc/yum.repos.d/`.  
> 🎯 **Trọng tâm phỏng vấn DevOps**: Lệnh rpm (-qa, -ql, -qf), lệnh dnf (install -y, search, provides), thư mục /etc/yum.repos.d/.

## 2. 📚 Lý Thuyết Chuyên Sâu & Bản Chất Hệ Thống (Under The Hood Mechanics)

### 2.1 Bản Chất Trình Quản Lý Gói RHEL
- `rpm`: Thao tác trực tiếp file `.rpm`. Lưu database tại `/var/lib/rpm/`.
  - `rpm -qa`: Query All (Liệt kê tất cả gói đã cài).
  - `rpm -ql package`: Liệt kê các file do gói tạo ra.
  - `rpm -qf /path/to/file`: Tìm gói nguồn sở hữu file đó.
- `dnf` / `yum`: Đọc file repo tại `/etc/yum.repos.d/*.repo`.
  - `dnf provides /path/to/file`: Tìm gói phần mềm cung cấp file/lệnh đó.

## 4. 🛠 Thao Tác Thực Chiến & Kịch Bản DevOps (Real-World Scenarios)

### 🛠 Các lệnh thực hành gõ là ăn ngay:
```bash
# Tìm xem câu lệnh 'htop' do gói phần mềm nào cung cấp:
dnf provides htop

# Cài đặt gói htop:
sudo dnf install -y htop
```

### 🚀 Kịch bản xử lý sự cố thực tế khi đi làm:
Cấu hình repo nội bộ cho Amazon Linux 2023:
sudo dnf install -y docker-ce

## 5. 🚀 Bộ Câu Hỏi Phỏng Vấn DevOps Thực Tế (Interview Q&A)

> **Q: Thư mục nào chứa danh sách file .repo của DNF/YUM?**  
> **A**: Thư mục `/etc/yum.repos.d/`.

> **Q: Lệnh nào tìm gói phần mềm cung cấp một file cụ thể trên RHEL?**  
> **A**: Dùng lệnh `dnf provides /path/to/file` hoặc `rpm -qf /path/to/file`.
