# 🐧 Objective 102.6: Linux Trong Máy Ảo & Cloud Instance (cloud-init) - Bản Chất Hệ Thống & Thực Chiến DevOps

> 💡 **Bản chất 1 câu**: Khởi tạo Linux Guest trên Cloud (AWS/GCP), `cloud-init` tự động nạp SSH Key, hostname và script khởi tạo khi boot lần đầu.  
> 🎯 **Trọng tâm phỏng vấn DevOps**: Hypervisor Type-1 vs Type-2, công cụ cloud-init (/etc/cloud/cloud.cfg), systemd-detect-virt.

---

## 1. 🧠 Hình Hình Dung Nhanh (Intuitive Mindset)

`cloud-init` như người phục vụ khách sạn: Khi EC2 Instance mới mở cửa, `cloud-init` tự mang chìa khóa SSH Key vào phòng và setup tên máy tính.

---

## 2. 📚 Lý Thuyết Chuyên Sâu & Bản Chất Hệ Thống (Under The Hood Mechanics)

### 2.1 Bản Chất Ảo Hóa & Cloud-init
- **Hypervisor Type 1 (Bare-metal)**: KVM, Xen (AWS EC2 dùng). Chạy trực tiếp trên phần cứng.
- **Hypervisor Type 2 (Hosted)**: VirtualBox, VMware Workstation.
- **`cloud-init`**: Công cụ tự động chạy khi boot lần đầu trên Cloud:
  - Đọc Metadata từ `http://169.254.169.254/`.
  - Cấu hình Hostname, inject SSH Key vào `~/.ssh/authorized_keys`, chạy script User-data.

## 5. 🚀 Bộ Câu Hỏi Phỏng Vấn DevOps Thực Tế (Interview Q&A)

> **Q: Công cụ nào tự động nạp SSH Key và Hostname khi tạo EC2 trên AWS?**

> **Q: Lệnh nào kiểm tra xem máy hiện tại là KVM, Docker hay Bare-metal?**
