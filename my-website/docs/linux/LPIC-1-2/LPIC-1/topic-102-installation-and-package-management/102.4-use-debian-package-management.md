# 🐧 Objective 102.4: Trình Quản Lý Gói Debian (dpkg & APT) - Bản Chất Hệ Thống & Thực Chiến DevOps

> 💡 **Bản chất 1 câu**: Quản lý phần mềm trên Ubuntu/Debian: `dpkg` thao tác file `.deb` cục bộ, `apt` quản lý kho gói tự động qua mạng.  
> 🎯 **Trọng tâm phỏng vấn DevOps**: Lệnh dpkg (-i, -l, -L), lệnh apt (update, install -y, purge), file /etc/apt/sources.list.

---

## 1. 🧠 Hình Hình Dung Nhanh (Intuitive Mindset)

`dpkg` như mua hàng xách tay về tự cài (không tự tải đồ thiếu). `apt` như siêu thị online, chọn phần mềm là tự shipper giao và tải đủ phụ thuộc.

---

## 2. 📚 Lý Thuyết Chuyên Sâu & Bản Chất Hệ Thống (Under The Hood Mechanics)

### 2.1 Bản Chất Trình Quản Lý Gói Debian
- `dpkg`: Thao tác trực tiếp trên gói `.deb` cục bộ. Lưu cơ sở dữ liệu các gói tại `/var/lib/dpkg/`.
  - `dpkg -L package`: Xem danh sách toàn bộ file do gói đó tạo ra.
  - `dpkg -S /path/to/file`: Xem file thuộc gói nào.
- `apt` / `apt-get`: Đọc URL kho phần mềm tại `/etc/apt/sources.list` và `/etc/apt/sources.list.d/*.list`.
  - `apt update`: Tải thông tin danh sách gói (Package Metadata).
  - `apt purge`: Xóa gói và xóa sạch file cấu hình.


---

## 3. ⚡ Bảng Tra Cứu Câu Lệnh Thực Hành (CLI Command Reference)

| Câu lệnh | Tham số (Options/Flags) | Giải thích ý nghĩa chi tiết | Ví dụ thực tế trong DevOps |
| :--- | :--- | :--- | :--- |
| **`dpkg`** | `Quản lý gói .deb cục bộ` | -i, -l, -L | `dpkg -L nginx` |
| **`apt`** | `Quản lý gói tự động qua mạng` | update, install -y, purge | `sudo apt update && sudo apt install -y docker.io` |


---

## 4. 🛠 Thao Tác Thực Chiến & Kịch Bản DevOps (Real-World Scenarios)

### 🛠 Các lệnh thực hành gõ là ăn ngay:
```bash
# Cài đặt Docker trên Ubuntu chuẩn DevOps:
sudo apt update && sudo apt install -y docker.io

# Xem các file do gói nginx cài ra:
dpkg -L nginx
```

### 🚀 Kịch bản xử lý sự cố thực tế khi đi làm:
Tối ưu Dockerfile layer:
RUN apt-get update && apt-get install -y curl git && rm -rf /var/lib/apt/lists/*

## 5. 🚀 Bộ Câu Hỏi Phỏng Vấn DevOps Thực Tế (Interview Q&A)

> **Q: File nào chứa danh sách Repository URL của APT?**  
> **A**: File `/etc/apt/sources.list`.

> **Q: Sự khác biệt giữa `apt remove` và `apt purge` là gì?**  
> **A**: `remove` chỉ xóa ứng dụng giữ lại config; `purge` xóa sạch cả ứng dụng lẫn file config.
