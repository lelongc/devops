# 🐧 Objective 110.3: Mã Hóa SSH Keypair, SSH Tunnel & GnuPG / GPG (LPI 102-500) - Bản Chất Hệ Thống & Thực Chiến DevOps

> 💡 **Bản chất 1 câu**: Quản lý SSH Keypair, mã hóa cấu hình SSH Server (/etc/ssh/sshd_config), SSH Tunneling và sử dụng GnuPG (`gpg`) để mã hóa/giải nén file và chữ ký số.  
> 🎯 **Trọng tâm phỏng vấn DevOps**: OpenSSH Client/Server config, SSH Host Keys (/etc/ssh/ssh_host_*), SSH Tunnel (-L, -R, -D), GnuPG / GPG (gpg --gen-key, --encrypt, --decrypt, --sign, --verify, --import, --export).

## 1. 🧠 Hình Hình Dung Nhanh (Intuitive Mindset)

GnuPG (GPG) như một két sắt kỹ thuật số có 2 chìa khóa: Public Key dùng để khóa két sắt lại (mọi người đều có thể khóa hộ bạn), còn Private Key là chiếc chìa khóa duy nhất nằm trong tay bạn để mở két ra đọc tài liệu bí mật.

## 2. 📚 Lý Thuyết Chuyên Sâu & Bản Chất Hệ Thống (Under The Hood Mechanics - LPI Official 101 & 102)

### 2.1 Mã Hóa Truyền Tin & Mã Hóa Tệp Dữ Liệu

1. **Bảo Mật Đăng Nhập SSH Server (/etc/ssh/sshd_config)**:
   - Các SSH Host Keys của Server nằm tại `/etc/ssh/ssh_host_rsa_key`, `/etc/ssh/ssh_host_ed25519_key`.
   - File cấu hình Client: `~/.ssh/config` (giúp lưu sẵn IP, Port, User, IdentityFile để gõ lệnh `ssh app-server` nhanh gọn).
   - **Các dạng SSH Tunneling**:
     - `Local Port Forwarding (-L)`: `ssh -L 3306:private_db:3306 user@bastion` (Thông port DB từ local qua Bastion).
     - `Remote Port Forwarding (-R)`: `ssh -R 8080:localhost:80 user@public_vps` (Public web local ra VPS ngoài internet).
     - `Dynamic SOCKS Proxy (-D)`: `ssh -D 1080 user@bastion` (Tạo Proxy mã hóa toàn bộ lượng truy cập web qua SSH).

2. **Mã Hóa Dữ Liệu & Chữ Ký Số Bằng GnuPG (GPG)**:
   - GnuPG triển khai tiêu chuẩn mã hóa OpenPGP (RFC 4880).
   - **Tạo & Quản Lý Cặp Khóa GPG**:
     - `gpg --full-generate-key`: Tạo cặp khóa GPG Public/Private key mới.
     - `gpg --list-keys`: Liệt kê các Public Key có trong chìa khóa (keyring).
     - `gpg --export -a "User" > public.key`: Xuất Public Key dạng ASCII Armor để gửi cho đối tác.
     - `gpg --import public.key`: Nhập Public Key của đối tác vào máy.
     - `gpg --gen-revoke "User" > revoke.asc`: Tạo chứng chỉ thu hồi (Revocation Certificate) dùng khi lộ khóa.
   - **Thao Tác Mã Hóa & Giải Mã File**:
     - **Mã hóa file gửi đối tác**: `gpg --encrypt --recipient "partner@email.com" secret.txt` (Sinh file `secret.txt.gpg`).
     - **Giải mã file nhận được**: `gpg --decrypt secret.txt.gpg > secret.txt` (Dùng Private Key cá nhân và nhập Passphrase).
     - **Tạo chữ ký số (Sign)**: `gpg --sign file.txt` hoặc `gpg --clearsign file.txt`.
     - **Xác thực chữ ký số (Verify)**: `gpg --verify file.txt.asc`.

## 3. ⚡ Bảng Tra Cứu Câu Lệnh Thực Hành (CLI Command Reference)

| Câu lệnh | Tham số (Options/Flags) | Giải thích ý nghĩa chi tiết | Ví dụ thực tế trong DevOps |
| :--- | :--- | :--- | :--- |
| **`ssh-keygen`** | `Tạo cặp SSH Keypair (ED25519/RSA)` | -t ed25519 | `ssh-keygen -t ed25519` |
| **`ssh-copy-id`** | `Copy Public Key lên Server tự động` | user@host | `ssh-copy-id ubuntu@10.0.0.1` |
| **`gpg --full-generate-key`** | `Tạo cặp khóa GPG Public/Private Key mới` | Không | `gpg --full-generate-key` |
| **`gpg --encrypt`** | `Mã hóa file bằng Public Key của người nhận` | -r recipient file | `gpg -e -r devops secret.txt` |
| **`gpg --decrypt`** | `Giải mã file .gpg bằng Private Key cá nhân` | file.gpg | `gpg -d secret.txt.gpg` |
| **`gpg --sign / --verify`** | `Ký chữ ký số vào file và xác thực chữ ký` | file | `gpg --verify document.txt.asc` |

## 4. 🛠 Thao Tác Thực Chiến & Kịch Bản DevOps (Real-World Scenarios)

### 🛠 Các lệnh thực hành gõ là ăn ngay:
```bash
# 1. Tạo SSH Tunnel thông Port PostgreSQL 5432 riêng tư từ AWS qua Bastion Host:
ssh -L 5432:10.0.2.100:5432 ubuntu@bastion.company.com -N -f

# 2. Quy trình GPG Mã hóa file cấu hình nhạy cảm gửi cho Team:
gpg --import team_lead_pubkey.asc
gpg --encrypt --armor --recipient "teamlead@company.com" db_credentials.env
# Kết quả tạo ra file db_credentials.env.asc an toàn tuyệt đối
```

### 🚀 Kịch bản xử lý sự cố thực tế khi đi làm:
Mã hóa file đính kèm gửi qua Email trong doanh nghiệp:
gpg --encrypt --armor -r CEO@company.com audit_report.pdf

## 5. 🚀 Bộ Câu Hỏi Phỏng Vấn DevOps Thực Tế (Interview Q&A)

> **Q: Sự khác biệt giữa SSH Local Port Forwarding (`-L`) và Remote Port Forwarding (`-R`) là gì?**  
> **A**: `-L` mở cổng ở máy Local chuyển tiếp tới Server từ xa; `-R` mở cổng ở Server từ xa chuyển tiếp ngược về máy Local.

> **Q: Lệnh GPG nào dùng để mã hóa một file văn bản cho người nhận cụ thể?**  
> **A**: Lệnh `gpg --encrypt --armor --recipient "user@email.com" filename`.

> **Q: Chứng chỉ thu hồi (Revocation Certificate) trong GPG dùng để làm gì?**  
> **A**: Dùng để thông báo cho toàn bộ mạng lưới biết cặp khóa GPG đó đã bị lộ hoặc không còn tin cậy để thu hồi khóa.
