# 🐧 Objective 107.3: Quản Lý Múi Giờ & Ngôn Ngữ (timedatectl & locale) - Bản Chất Hệ Thống & Thực Chiến DevOps

> 💡 **Bản chất 1 câu**: Đồng bộ múi giờ hệ thống (Timezone) với `timedatectl` và cấu hình ngôn ngữ hiển thị hệ thống với `localectl` / `LANG`.  
> 🎯 **Trọng tâm phỏng vấn DevOps**: Lệnh timedatectl set-timezone, localectl set-locale, biến LANG, LC_ALL.

---

## 1. 🧠 Hình Hình Dung Nhanh (Intuitive Mindset)

Trên Cloud (AWS EC2), luôn cài đặt Timezone hệ thống đồng bộ về `UTC` hoặc `Asia/Ho_Chi_Minh` để log ghi ra đúng mốc thời gian.

---

## 2. 📚 Lý Thuyết Chuyên Sâu & Bản Chất Hệ Thống (Under The Hood Mechanics)

### 2.1 Bản Chất Múi Giờ & Locale
- Cơ sở dữ liệu múi giờ nằm tại `/usr/share/zoneinfo/`.
- File `/etc/localtime` là một Symlink trỏ tới file timezone trong `/usr/share/zoneinfo/`.
- `timedatectl set-timezone Asia/Ho_Chi_Minh` tự động cập nhật symlink này.


---

## 3. ⚡ Bảng Tra Cứu Câu Lệnh Thực Hành (CLI Command Reference)

| Câu lệnh | Tham số (Options/Flags) | Giải thích ý nghĩa chi tiết | Ví dụ thực tế trong DevOps |
| :--- | :--- | :--- | :--- |
| **`timedatectl`** | `Quản lý thời gian và múi giờ hệ thống` | set-timezone | `sudo timedatectl set-timezone Asia/Ho_Chi_Minh` |
| **`localectl`** | `Cấu hình ngôn ngữ hệ thống locale` | set-locale | `localectl set-locale LANG=en_US.UTF-8` |


---

## 4. 🛠 Thao Tác Thực Chiến & Kịch Bản DevOps (Real-World Scenarios)

### 🛠 Các lệnh thực hành gõ là ăn ngay:
```bash
# Đặt múi giờ Server về Việt Nam:
sudo timedatectl set-timezone Asia/Ho_Chi_Minh
```

### 🚀 Kịch bản xử lý sự cố thực tế khi đi làm:
Cấu hình timezone UTC:
sudo timedatectl set-timezone UTC

## 5. 🚀 Bộ Câu Hỏi Phỏng Vấn DevOps Thực Tế (Interview Q&A)

> **Q: Lệnh chuẩn nào đặt múi giờ máy chủ Linux về Việt Nam?**  
> **A**: Lệnh `sudo timedatectl set-timezone Asia/Ho_Chi_Minh`.

> **Q: Biến môi trường nào quyết định ngôn ngữ hiển thị chính của hệ thống?**  
> **A**: Biến môi trường `LANG` (hoặc `LC_ALL`).
