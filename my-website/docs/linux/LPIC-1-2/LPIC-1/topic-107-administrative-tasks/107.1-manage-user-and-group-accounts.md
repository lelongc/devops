## 2. 📚 Lý Thuyết Chuyên Sâu & Bản Chất Hệ Thống (Under The Hood Mechanics)

### 2.1 Bản Chất Quản Lý Tài Khoản User
- `/etc/passwd`: Chứa thông tin User (Username, Password placeholder 'x', UID, GID, Full Name, Home Dir, Shell).
- `/etc/shadow`: Lưu hash mật khẩu mã hóa (SHA-512/Yescrypt) chỉ root truy cập được.
- `usermod -aG`: Cờ `-a` (append) cực kỳ quan trọng để thêm group mới mà KHÔNG xóa các group cũ.


---

## 3. ⚡ Bảng Tra Cứu Câu Lệnh Thực Hành (CLI Command Reference)

| Câu lệnh | Tham số (Options/Flags) | Giải thích ý nghĩa chi tiết | Ví dụ thực tế trong DevOps |
| :--- | :--- | :--- | :--- |
| **`useradd`** | `Tạo tài khoản người dùng mới` | -m, -s | `sudo useradd -m -s /bin/bash devops` |
| **`usermod`** | `Chỉnh sửa thông tin/nhóm người dùng` | -aG | `sudo usermod -aG docker devops` |
| **`passwd`** | `Đặt hoặc thay đổi mật khẩu user` | username | `sudo passwd devops` |


---

## 4. 🛠 Thao Tác Thực Chiến & Kịch Bản DevOps (Real-World Scenarios)

### 🛠 Các lệnh thực hành gõ là ăn ngay:
```bash
# Tạo user 'developer' và thêm vào nhóm docker:
sudo useradd -m -s /bin/bash developer
sudo usermod -aG docker developer
```

### 🚀 Kịch bản xử lý sự cố thực tế khi đi làm:
Cấp quyền Docker cho user:
sudo usermod -aG docker devops

## 5. 🚀 Bộ Câu Hỏi Phỏng Vấn DevOps Thực Tế (Interview Q&A)

> **Q: File nào trên Linux lưu trữ mật khẩu đã được mã hóa Hash của người dùng?**  
> **A**: File `/etc/shadow`.

> **Q: Làm sao thêm một User vào một Group bổ sung mà KHÔNG làm mất các Group cũ?**  
> **A**: Dùng lệnh `sudo usermod -aG <group_name> <username>`.
