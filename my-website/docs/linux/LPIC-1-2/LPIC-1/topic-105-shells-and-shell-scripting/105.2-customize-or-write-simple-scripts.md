## 2. 📚 Lý Thuyết Chuyên Sâu & Bản Chất Hệ Thống (Under The Hood Mechanics - LPI Official 101 & 102)

### 2.1 Kiến Trúc & Cấu Trúc Bash Script Chuẩn Doanh Nghiệp
1. **Dòng Shebang (`#!/bin/bash` hoặc `#!/usr/bin/env bash`)**:
   - Khi thực thi script dạng `./script.sh`, Kernel đọc 2 byte đầu tiên `#!` (Magic bytes) để gọi đúng trình thông dịch `/bin/bash`.
2. **Biến Vị Trí & Biến Đặc Biệt (Positional & Special Parameters)**:
   - `$0`: Tên của script đang chạy.
   - `$1`, `$2`, ..., `$9`: Các tham số truyền vào từ dòng lệnh. Với tham số >= 10 dùng `${10}`.
   - `$#`: Tổng số lượng tham số truyền vào script.
   - `$@` hoặc `$*`: Danh sách tất cả các tham số. `$@` giữ nguyên phân cách từng chuỗi khi bọc trong `"..."`.
   - `$?`: Mã thoát Exit Code của lệnh trước đó (0 = Thành công, khác 0 = Lỗi).
   - `$$`: PID của tiến trình script đang chạy.
3. **Phép Toán Số Học (Arithmetic Expressions)**:
   - Cú pháp chuẩn BASH: `RESULT=$(( A + B ))` hoặc `let RESULT=A+B`.
4. **Biểu Thức Kiểm Tra Điều Kiện (Conditionals & Extended Tests)**:
   - Lệnh `test` hoặc `[ ... ]` (POSIX standard): Cần dấu cách quanh ngoặc vuông.
     - So sánh số: `-eq` (equal), `-ne` (not equal), `-gt` (greater than), `-lt` (less than), `-ge`, `-le`.
     - So sánh chuỗi: `=` hoặc `==`, `!=`, `-z` (chuỗi rỗng), `-n` (chuỗi không rỗng).
     - Kiểm tra file: `-f` (file tồn tại), `-d` (thư mục tồn tại), `-e` (tồn tại), `-r`/`-w`/`-x` (quyền đọc/ghi/chạy).
   - Cấu trúc mở rộng `[[ ... ]]` (BASH specific): Hỗ trợ so sánh Regex `=~`, toán tử `&&` và `||` trực tiếp.
5. **Vòng Lặp & Cấu Trúc Điều Điều Khiển**:
   - `for var in list; do ... done`
   - `while [ condition ]; do ... done` (Chạy khi điều kiện ĐÚNG)
   - `until [ condition ]; do ... done` (Chạy khi điều kiện SAI)
   - `case "$var" in pattern1) ... ;; pattern2) ... ;; *) ... esac`

## 4. 🛠 Thao Tác Thực Chiến & Kịch Bản DevOps (Real-World Scenarios)

### 🛠 Các lệnh thực hành gõ là ăn ngay:
```bash
# Script tự động kiểm tra Disk và gửi cảnh báo:
#!/bin/bash
set -e
THRESHOLD=80
USAGE=$(df / | grep / | awk '{print $5}' | sed 's/%//')
if [ "$USAGE" -gt "$THRESHOLD" ]; then
    echo "CRITICAL: Disk usage is ${USAGE}%" | mail -s "Disk Warning" admin@company.com
fi
```

### 🚀 Kịch bản xử lý sự cố thực tế khi đi làm:
Kịch bản deploy tự động tích hợp CI/CD Pipeline:
#!/bin/bash
set -euo pipefail

echo "=== Building App ==="
./build.sh

echo "=== Running Tests ==="
./test.sh

echo "=== Deploying ==="
./deploy.sh

## 5. 🚀 Bộ Câu Hỏi Phỏng Vấn DevOps Thực Tế (Interview Q&A)

> **Q: Biến đặc biệt nào chứa TỔNG SỐ LƯỢNG tham số truyền vào Bash Script?**  
> **A**: Biến `$#`.

> **Q: Sự khác biệt giữa `[ ... ]` và `[[ ... ]]` trong BASH là gì?**  
> **A**: `[ ... ]` là cú pháp test chuẩn POSIX legacy; `[[ ... ]]` là mở rộng của BASH hỗ trợ toán tử Regex `=~` và `&&`/`||` an toàn hơn.

> **Q: Tùy chọn `set -euo pipefail` ở đầu script có ý nghĩa gì trong DevOps?**  
> **A**: `set -e` dừng khi có lỗi; `set -u` báo lỗi nếu dùng biến chưa khai báo; `pipefail` bắt lỗi ở bất kỳ vị trí nào trong chuỗi pipe `|`.
