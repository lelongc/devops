# 🐧 Objective 105.1: Tùy Biến Môi Trường Shell, Biến & Alias (LPI 102-500) - Bản Chất Hệ Thống & Thực Chiến DevOps

> 💡 **Bản chất 1 câu**: Quản lý Shell environment, phân biệt Login vs Non-Login, Interactive vs Non-Interactive Shell, biến môi trường (export/env/set) và hàm/alias trong BASH.  
> 🎯 **Trọng tâm phỏng vấn DevOps**: Thứ tự nạp file startup (/etc/profile, ~/.bash_profile, ~/.bashrc), phân biệt biến Shell (Local) vs biến Môi trường (Global), hàm BASH và Alias.

---

## 1. 🧠 Hình Hình Dung Nhanh (Intuitive Mindset)

BASH Shell như một phòng làm việc cá nhân: Khi mở cửa bước vào phòng (Login Shell), hệ thống đọc nội quy chung (/etc/profile) rồi nạp trang trí cá nhân (~/.bash_profile). Khi mở thêm bàn làm việc mới (Interactive Non-login Shell), hệ thống đọc file ghi chú ~/.bashrc.

---

## 2. 📚 Lý Thuyết Chuyên Sâu & Bản Chất Hệ Thống (Under The Hood Mechanics - LPI Official 101 & 102)

### 2.1 Bản Chất Các Loại Shell Trong Linux (Shell Types & Startup Files)
Linux phân chia Shell thành 2 chiều độc lập:

1. **Login Shell vs Non-Login Shell**:
   - **Login Shell** (Khi đăng nhập SSH hoặc gõ `su - user`):
     - Thứ tự nạp file cấu hình:
       1. `/etc/profile` (Cấu hình toàn hệ thống cho mọi user).
       2. `/etc/profile.d/*.sh` (Các script cấu hình ứng dụng).
       3. File cấu hình cá nhân đầu tiên tìm thấy: `~/.bash_profile` -> `~/.bash_login` -> `~/.profile`.
       4. Khi đăng xuất (Logout): Nạp `~/.bash_logout`.
   - **Non-Login Interactive Shell** (Khi mở Terminal mới trong GUI hoặc gõ `bash`):
     - Thứ tự nạp: `/etc/bash.bashrc` -> `~/.bashrc`.

2. **Interactive vs Non-Interactive Shell**:
   - **Interactive**: Kết nối bàn phím/màn hình có nhắc lệnh `$PS1`.
   - **Non-Interactive**: Chạy script tự động không qua bàn phím.

---

### 2.2 Quản Lý Biến Môi Trường, Hàm BASH & Alias
- **Local Variable (Shell Variable)**: Khai báo `VAR=val`. Chỉ có hiệu lực trong Shell hiện tại, không truyền xuống tiến trình con.
- **Global Variable (Environment Variable)**: Khai báo `export VAR=val`. Được sao chép vào khối nhớ `environ` của mọi tiến trình con (Child Processes).
- **Các lệnh quản lý biến**:
  - `set`: Liệt kê TOÀN BỘ biến Shell (cả local và global) cùng các hàm.
  - `env` / `printenv`: Chỉ liệt kê các biến Môi trường toàn cục (Environment Variables).
  - `unset VAR`: Xóa bỏ biến khỏi bộ nhớ Shell.
- **Hàm BASH (BASH Functions)**:
  - Khai báo: `my_func() { echo "Hello $1"; }`
  - Ưu tiên thực thi: `Alias` -> `Keyword` -> `Function` -> `Builtin` -> `External Binary in PATH`.

## 3. ⚡ Bảng Tra Cứu Câu Lệnh Thực Hành (CLI Command Reference)

| Câu lệnh | Tham số (Options/Flags) | Giải thích ý nghĩa chi tiết | Ví dụ thực tế trong DevOps |
| :--- | :--- | :--- | :--- |
| **`export`** | `Đưa biến local thành biến môi trường toàn cục` | VAR=val | `export PATH=$PATH:/usr/local/bin` |
| **`env / printenv`** | `Hiển thị tất cả các biến môi trường toàn cục` | VAR_NAME | `printenv PATH` |
| **`set`** | `Xem tất cả các biến local, global và hàm trong Shell` | Không | `set | grep VAR` |
| **`unset`** | `Xóa biến khỏi bộ nhớ Shell` | VAR_NAME | `unset SECRET_KEY` |
| **`alias`** | `Tạo tên lệnh tắt ngắn gọn` | name='command' | `alias k='kubectl'` |
| **`source / .`** | `Đọc và thực thi file config trong Shell hiện tại` | filename | `source ~/.bashrc` |

## 4. 🛠 Thao Tác Thực Chiến & Kịch Bản DevOps (Real-World Scenarios)

### 🛠 Các lệnh thực hành gõ là ăn ngay:
```bash
# 1. Khai báo biến môi trường chuẩn DevOps:
export DATABASE_URL="postgresql://user:pass@localhost:5432/db"

# 2. Tạo Alias và Function trong ~/.bashrc:
echo "alias k='kubectl'" >> ~/.bashrc
echo "kns() { kubectl config set-context --current --namespace=\$1; }" >> ~/.bashrc
source ~/.bashrc
```

### 🚀 Kịch bản xử lý sự cố thực tế khi đi làm:
Debug lỗi không nhận biến môi trường trong CI/CD Runner:
# Kiểm tra biến có được export chưa:
printenv DATABASE_URL
# Nếu chưa có, thêm 'export' trong ~/.bashrc và source lại:
export DATABASE_URL="..."

## 5. 🚀 Bộ Câu Hỏi Phỏng Vấn DevOps Thực Tế (Interview Q&A)

> **Q: Thứ tự nạp file cấu hình khi người dùng đăng nhập qua SSH (Login Shell) là gì?**  
> **A**: Nạp `/etc/profile` -> `/etc/profile.d/*.sh` -> file cá nhân đầu tiên tìm thấy trong (`~/.bash_profile`, `~/.bash_login`, `~/.profile`).

> **Q: Lệnh nào liệt kê CHỈ các biến môi trường toàn cục (Global Environment Variables)?**  
> **A**: Lệnh `env` hoặc `printenv`.

> **Q: Sự khác biệt giữa `VAR=123` và `export VAR=123` là gì?**  
> **A**: `VAR=123` là local variable chỉ dùng trong Shell hiện tại; `export VAR=123` đưa biến vào môi trường để tiến trình con kế thừa.
