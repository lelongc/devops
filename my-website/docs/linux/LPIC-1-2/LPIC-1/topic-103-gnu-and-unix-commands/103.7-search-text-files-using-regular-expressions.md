# 🐧 Objective 103.7: Biểu Thức Chính Quy & Thay Thế Chuỗi (grep & sed) - Bản Chất Hệ Thống & Thực Chiến DevOps

> 💡 **Bản chất 1 câu**: Thành thạo `grep` tìm kiếm chuỗi biểu thức chính quy (Regex) và `sed -i` chỉnh sửa thay thế chuỗi trực tiếp trong file cấu hình.  
> 🎯 **Trọng tâm phỏng vấn DevOps**: Lệnh grep (-r, -i, -E, -v), lệnh sed (s/find/replace/g, -i edit in-place).

---

## 1. 🧠 Hình Hình Dung Nhanh (Intuitive Mindset)

`grep` như kính phóng đại để TÌM CHUỖI. `sed -i` như bút xóa thông minh để SỬA CHUỖI trực tiếp trong file mà không cần mở Editor.

---

## 2. 📚 Lý Thuyết Chuyên Sâu & Bản Chất Hệ Thống (Under The Hood Mechanics)

### 2.1 Bản Chất Regex Engine & sed Stream Processing
- `grep -E`: Sử dụng Extended Regular Expressions (ERE) hỗ trợ các toán tử `|`, `+`, `?`, `{}` không cần escape.
- `sed -i`: Stream Editor nạp từng dòng file vào **Pattern Space**, thực thi lệnh thay thế `s/old/new/g` rồi ghi trực tiếp đè lại file gốc (`-i`).


---

## 3. ⚡ Bảng Tra Cứu Câu Lệnh Thực Hành (CLI Command Reference)

| Câu lệnh | Tham số (Options/Flags) | Giải thích ý nghĩa chi tiết | Ví dụ thực tế trong DevOps |
| :--- | :--- | :--- | :--- |
| **`grep`** | `Tìm kiếm chuỗi theo Regex` | -i, -r, -E, -v | `grep -r -E 'ERROR|FATAL' /var/log/` |
| **`sed`** | `Stream Editor chỉnh sửa thay thế chuỗi` | s/old/new/g, -i | `sed -i 's/Port 22/Port 2222/g' /etc/ssh/sshd_config` |


---

## 4. 🛠 Thao Tác Thực Chiến & Kịch Bản DevOps (Real-World Scenarios)

### 🛠 Các lệnh thực hành gõ là ăn ngay:
```bash
# Thay thế cấu hình Port SSH tự động:
sudo sed -i 's/#Port 22/Port 2222/g' /etc/ssh/sshd_config
```

### 🚀 Kịch bản xử lý sự cố thực tế khi đi làm:
Thay thế biến môi trường trong file config:
sed -i 's/ENV=development/ENV=production/g' .env

---

## 5. 🚀 Bộ Câu Hỏi Phỏng Vấn DevOps Thực Tế (Interview Q&A)

> **Q: Cờ nào của sed dùng để chỉnh sửa trực tiếp nội dung file gốc?**  
> **A**: Cờ `sed -i` (edit in-place).

> **Q: Làm sao dùng grep lọc bỏ các dòng comment băt đầu bằng dấu #?**  
> **A**: Dùng `grep -v '^#' /etc/nginx/nginx.conf`.
