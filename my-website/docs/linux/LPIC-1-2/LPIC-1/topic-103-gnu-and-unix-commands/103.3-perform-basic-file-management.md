# 🐧 Objective 103.3: Quản Lý File & Nén Dữ Liệu (cp, mv, tar, find) - Bản Chất Hệ Thống & Thực Chiến DevOps

> 💡 **Bản chất 1 câu**: Thao tác file/thư mục cơ bản (`cp -r`, `mv`, `rm -rf`), nén/giải nén gói lưu trữ `tar -czvf` và `tar -xzvf`.  
> 🎯 **Trọng tâm phỏng vấn DevOps**: Lệnh cp -rp giữ nguyên permission, rm -rf xóa nguy hiểm, nén tar -czvf / tar -xzvf.

---

## 1. 🧠 Hình Hình Dung Nhanh (Intuitive Mindset)

`tar -czvf` = **C**reate **Z**ip **V**erbose **F**ile (Tạo nén). `tar -xzvf` = **X**tract **Z**ip **V**erbose **F**ile (Giải nén).

---

## 2. 📚 Lý Thuyết Chuyên Sâu & Bản Chất Hệ Thống (Under The Hood Mechanics)

### 2.1 Bản Chất Thao Tác File & Inode
- `cp -p`: Copy giữ nguyên inode metadata (Permission, UID, GID, Timestamps).
- `mv`: Nếu cùng partition thì chỉ thay đổi tên trong thư mục (Inode không đổi). Nếu khác partition thì copy rồi xóa file cũ.
- `tar`: Gom nhiều file thành 1 file dạng tape archive. Kết hợp tùy chọn `-z` để gọi thuật toán nén `gzip`.


---

## 3. ⚡ Bảng Tra Cứu Câu Lệnh Thực Hành (CLI Command Reference)

| Câu lệnh | Tham số (Options/Flags) | Giải thích ý nghĩa chi tiết | Ví dụ thực tế trong DevOps |
| :--- | :--- | :--- | :--- |
| **`cp`** | `Sao chép file/thư mục` | -r, -p | `cp -rp /src /dst` |
| **`tar`** | `Nén và giải nén file .tar.gz` | -czvf, -xzvf | `tar -czvf backup.tar.gz /etc` |
| **`rm`** | `Xóa file hoặc thư mục` | -r, -f | `rm -rf /tmp/test` |


---

## 4. 🛠 Thao Tác Thực Chiến & Kịch Bản DevOps (Real-World Scenarios)

### 🛠 Các lệnh thực hành gõ là ăn ngay:
```bash
# Nén thư mục /etc thành file backup.tar.gz:
tar -czvf /backup/etc_$(date +%F).tar.gz /etc

# Giải nén file backup:
tar -xzvf backup.tar.gz -C /tmp
```

### 🚀 Kịch bản xử lý sự cố thực tế khi đi làm:
Tự động nén backup thư mục web:
tar -czvf /backups/app_$(date +%F).tar.gz /var/www/html

---

## 5. 🚀 Bộ Câu Hỏi Phỏng Vấn DevOps Thực Tế (Interview Q&A)

> **Q: Cờ nào của lệnh tar dùng để NÉN file dạng .tar.gz?**  
> **A**: Cờ `-czvf` (c: create, z: gzip).

> **Q: Cờ nào của lệnh tar dùng để GIẢI NÉN file .tar.gz?**  
> **A**: Cờ `-xzvf` (x: extract, z: gzip).
