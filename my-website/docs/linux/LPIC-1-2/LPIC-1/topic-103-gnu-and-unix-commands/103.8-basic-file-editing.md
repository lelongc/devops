# 🐧 Objective 103.8: Chỉnh Sửa File Bằng Vi / Vim Editor - Bản Chất Hệ Thống & Thực Chiến DevOps

> 💡 **Bản chất 1 câu**: Thành thạo Vim Editor trên Linux Server: Chuyển đổi các chế độ Normal, Insert, Visual, Command và lưu thoát an toàn.  
> 🎯 **Trọng tâm phỏng vấn DevOps**: Vim modes (Normal, Insert, Colon Command), phím i, Esc, :wq, :q!, dd, yy, p, /search.

---

## 1. 🧠 Hình Hình Dung Nhanh (Intuitive Mindset)

Vim mặc định vào ở **Normal Mode** (Chế độ gõ lệnh). Nhấn `i` để sang **Insert Mode** (Chế độ soạn thảo). Nhấn `Esc` rồi gõ `:wq` để **Lưu và Thoát**.

---

## 2. 📚 Lý Thuyết Chuyên Sâu & Bản Chất Hệ Thống (Under The Hood Mechanics)

### 2.1 Bản Chất Các Chế Độ Vim Editor
Vim hoạt động theo máy trạng thái hữu hạn (Finite State Machine):
1. **Normal Mode** (Mặc định): Gõ lệnh di chuyển, xóa dòng (`dd`), copy (`yy`), paste (`p`).
2. **Insert Mode**: Nhấn `i` để vào, gõ văn bản bình thường. Nhấn `Esc` để quay về Normal Mode.
3. **Command Mode**: Nhấn `:` từ Normal Mode để ghi file (`:w`), thoát (`:q`), lưu thoát (`:wq`), hoặc thoát không lưu (`:q!`).


---

## 3. ⚡ Bảng Tra Cứu Câu Lệnh Thực Hành (CLI Command Reference)

| Câu lệnh | Tham số (Options/Flags) | Giải thích ý nghĩa chi tiết | Ví dụ thực tế trong DevOps |
| :--- | :--- | :--- | :--- |
| **`vim`** | `Chương trình chỉnh sửa file văn bản trên CLI` | Filename | `vim /etc/nginx/nginx.conf` |
| **`:wq`** | `Lưu thay đổi và thoát Vim` | Không | `:wq` |
| **`:q!`** | `Thoát Vim khẩn cấp KHÔNG lưu` | Không | `:q!` |


---

## 4. 🛠 Thao Tác Thực Chiến & Kịch Bản DevOps (Real-World Scenarios)

### 🛠 Các lệnh thực hành gõ là ăn ngay:
```bash
# Sửa config Nginx bằng Vim:
vim /etc/nginx/nginx.conf
```

### 🚀 Kịch bản xử lý sự cố thực tế khi đi làm:
Thao tác Vim chuẩn:
vim /etc/hosts
# i -> sửa -> Esc -> :wq

## 5. 🚀 Bộ Câu Hỏi Phỏng Vấn DevOps Thực Tế (Interview Q&A)

> **Q: Phím nào chuyển từ Normal Mode sang Insert Mode trong Vim?**  
> **A**: Phím `i` (Insert).

> **Q: Làm sao thoát Vim mà KHÔNG lưu các thay đổi?**  
> **A**: Gõ phím `Esc`, nhập `:q!` rồi bấm Enter.
