# 🐧 Objective 108.2: Quản Lý Log Hệ Thống (rsyslog, journalctl & logrotate) - Bản Chất Hệ Thống & Thực Chiến DevOps

> 💡 **Bản chất 1 câu**: Đọc log Systemd siêu tốc bằng `journalctl -u service -f`, thu thập log qua `rsyslog` và tự động xoay nén file log bằng `logrotate`.  
> 🎯 **Trọng tâm phỏng vấn DevOps**: Lệnh journalctl (-u, -f, --since), rsyslog (/etc/rsyslog.conf), logrotate (/etc/logrotate.d/).

---

## 1. 🧠 Hình Hình Dung Nhanh (Intuitive Mindset)

`journalctl -f` như mở cửa sổ chat xem trực tiếp ứng dụng đang in log gì. `logrotate` như nhân viên vệ sinh: Đêm đến gom log cũ nén lại, quá 7 ngày thì xóa đi.

---

## 2. 📚 Lý Thuyết Chuyên Sâu & Bản Chất Hệ Thống (Under The Hood Mechanics)

### 2.1 Bản Chất Systemd Journal & Logrotate
- `journald` thu thập log binary trực tiếp từ kernel, stdout/stderr của dịch vụ systemd tại `/var/log/journal/`.
- `journalctl -u nginx -f`: Đọc stream log binary live.
- `logrotate`: Chạy theo lịch Cron đọc các file trong `/etc/logrotate.d/*` để cắt nén log (rotate, compress, delaycompress, retention).


---

## 3. ⚡ Bảng Tra Cứu Câu Lệnh Thực Hành (CLI Command Reference)

| Câu lệnh | Tham số (Options/Flags) | Giải thích ý nghĩa chi tiết | Ví dụ thực tế trong DevOps |
| :--- | :--- | :--- | :--- |
| **`journalctl`** | `Truy vấn log hệ thống binary của Systemd` | -u, -f, --since | `journalctl -u nginx -f` |
| **`logrotate`** | `Quản lý cắt, nén và xoay vòng file log` | -f | `sudo logrotate -f /etc/logrotate.conf` |


---

## 4. 🛠 Thao Tác Thực Chiến & Kịch Bản DevOps (Real-World Scenarios)

### 🛠 Các lệnh thực hành gõ là ăn ngay:
```bash
# Xem log live stream của Nginx:
journalctl -u nginx -f -n 100
```

### 🚀 Kịch bản xử lý sự cố thực tế khi đi làm:
Xem log 10 phút gần đây:
journalctl -u docker --since '10 minutes ago'

## 5. 🚀 Bộ Câu Hỏi Phỏng Vấn DevOps Thực Tế (Interview Q&A)

> **Q: Lệnh nào xem log live stream của một dịch vụ Systemd?**  
> **A**: Lệnh `journalctl -u <service_name> -f`.

> **Q: Công cụ nào tự động nén và xóa các file log cũ để tránh làm đầy đĩa?**  
> **A**: Công cụ `logrotate`.
