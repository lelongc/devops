# 🐧 Objective 108.3: Cơ Bản Về Mail Transfer Agent (MTA: Postfix) - Bản Chất Hệ Thống & Thực Chiến DevOps

> 💡 **Bản chất 1 câu**: Cơ chế dịch vụ gửi email trên Linux Server (Postfix), xem hàng chờ mail `mailq` và định tuyến email nội bộ `/etc/aliases`.  
> 🎯 **Trọng tâm phỏng vấn DevOps**: MTA Postfix, lệnh mailq (postqueue -p), file /etc/aliases, newaliases.

---

## 1. 🧠 Hình Hình Dung Nhanh (Intuitive Mindset)

MTA (Postfix) như bưu điện trên Server: Khi script có thông báo báo lỗi, Postfix nhận thư và gửi tới hộp thư của SysAdmin.

---

## 2. 📚 Lý Thuyết Chuyên Sâu & Bản Chất Hệ Thống (Under The Hood Mechanics)

### 2.1 Bản Chất MTA Mail Flow
MTA (Mail Transfer Agent) Postfix nhận thư qua SMTP port 25. `/etc/aliases` chuyển tiếp mail local user (root) tới địa chỉ email thực tế. `newaliases` biên dịch file alias sang database Berkley DB.


---

## 3. ⚡ Bảng Tra Cứu Câu Lệnh Thực Hành (CLI Command Reference)

| Câu lệnh | Tham số (Options/Flags) | Giải thích ý nghĩa chi tiết | Ví dụ thực tế trong DevOps |
| :--- | :--- | :--- | :--- |
| **`mailq`** | `Xem danh sách email đang nằm trong hàng chờ chưa gửi` | Không | `mailq` |
| **`newaliases`** | `Cập nhật lại cơ sở dữ liệu chuyển tiếp email` | Không | `sudo newaliases` |


---

## 5. 🚀 Bộ Câu Hỏi Phỏng Vấn DevOps Thực Tế (Interview Q&A)

> **Q: File nào định nghĩa chuyển tiếp email của các user hệ thống?**  
> **A**: File `/etc/aliases`.

> **Q: Lệnh nào kiểm tra danh sách email đang nằm trong Mail Queue?**  
> **A**: Lệnh `mailq` (hoặc `postqueue -p`).
