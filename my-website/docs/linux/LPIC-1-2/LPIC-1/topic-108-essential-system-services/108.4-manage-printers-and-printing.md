# 🐧 Objective 108.4: Quản Lý Hệ Thống In Ấn (CUPS) - Bản Chất Hệ Thống & Thực Chiến DevOps

> 💡 **Bản chất 1 câu**: Quản lý máy in trên Linux qua hệ thống CUPS (Common UNIX Printing System), lệnh `lpstat` và `cancel`.  
> 🎯 **Trọng tâm phỏng vấn DevOps**: CUPS service (Port 631), lệnh lp, lpr, lpstat, cancel.

---

## 1. 🧠 Hình Hình Dung Nhanh (Intuitive Mindset)

CUPS quản lý máy in trên Linux Server, cung cấp giao diện Web Admin tại cổng `http://localhost:631`.

---

## 2. 📚 Lý Thuyết Chuyên Sâu & Bản Chất Hệ Thống (Under The Hood Mechanics)

### 2.1 Bản Chất CUPS Protocol
CUPS chạy daemon IPP (Internet Printing Protocol) quản lý hàng chờ in và giao diện web admin tại Port 631.


---

## 3. ⚡ Bảng Tra Cứu Câu Lệnh Thực Hành (CLI Command Reference)

| Câu lệnh | Tham số (Options/Flags) | Giải thích ý nghĩa chi tiết | Ví dụ thực tế trong DevOps |
| :--- | :--- | :--- | :--- |
| **`lpstat`** | `Xem danh sách máy in và lệnh in đang chờ` | -p, -o | `lpstat -p` |
| **`cancel`** | `Hủy một lệnh in đang chờ` | job_id | `cancel 101` |
