# 🐧 Objective 104.6: Quản Lý Hard Link & Symbolic Link (ln & ln -s) - Bản Chất Hệ Thống & Thực Chiến DevOps

> 💡 **Bản chất 1 câu**: Phân biệt Hard Link (dùng chung số Inode, cùng partition) và Symbolic Soft Link (tệp trỏ shortcut, dùng được xuyên partition).  
> 🎯 **Trọng tâm phỏng vấn DevOps**: Lệnh ln (Hard link) vs ln -s (Symbolic soft link), đặc điểm số Inode.

---

## 1. 🧠 Hình Hình Dung Nhanh (Intuitive Mindset)

Hard Link như 2 cái tên cùng gọi 1 người (xóa 1 tên người đó vẫn sống). Symbolic Soft Link như một lối tắt Shortcut trên Windows (xóa file gốc thì shortcut bị đứt gãy).

---

## 2. 📚 Lý Thuyết Chuyên Sâu & Bản Chất Hệ Thống (Under The Hood Mechanics)

### 2.1 Bản Chất Inode Linking
- **Hard Link**: Thêm một bản ghi Directory Entry mới trỏ tới cùng một số Inode trên đĩa. Không tăng dung lượng đĩa. Không tạo được cho thư mục và không trỏ xuyên partition khác.
- **Symbolic Link (`ln -s`)**: Tạo một Inode hoàn toàn mới chứa chuỗi đòn dẫn trỏ tới target file. Tạo được cho thư mục và xuyên partition.


---

## 3. ⚡ Bảng Tra Cứu Câu Lệnh Thực Hành (CLI Command Reference)

| Câu lệnh | Tham số (Options/Flags) | Giải thích ý nghĩa chi tiết | Ví dụ thực tế trong DevOps |
| :--- | :--- | :--- | :--- |
| **`ln`** | `Tạo Hard Link (dùng chung Inode)` | target link | `ln file.txt hardlink.txt` |
| **`ln -s`** | `Tạo Symbolic Soft Link (Shortcut)` | target link | `ln -s /etc/nginx/sites-available/app /etc/nginx/sites-enabled/app` |


---

## 4. 🛠 Thao Tác Thực Chiến & Kịch Bản DevOps (Real-World Scenarios)

### 🛠 Các lệnh thực hành gõ là ăn ngay:
```bash
# Tạo Symlink bật Nginx site:
sudo ln -s /etc/nginx/sites-available/my_app.conf /etc/nginx/sites-enabled/my_app.conf
```

### 🚀 Kịch bản xử lý sự cố thực tế khi đi làm:
Tạo shortcut log:
ln -s /var/log/nginx/access.log ~/access.log

---

## 5. 🚀 Bộ Câu Hỏi Phỏng Vấn DevOps Thực Tế (Interview Q&A)

> **Q: Đặc điểm nổi bật của Symbolic Link so với Hard Link?**  
> **A**: Symbolic Link có thể trỏ tới thư mục và trỏ xuyên các phân đĩa khác nhau.

> **Q: Điều gì xảy ra với Hard Link khi file gốc bị xóa?**  
> **A**: Dữ liệu vẫn tồn tại an toàn vì số Inode vẫn còn đếm liên kết.



---

## 6. 📝 Cheat Sheet & Ghi Nhớ Nhanh (Summary)

- [x] ln file link: Hard Link (Cùng Inode, cùng ổ đĩa)
- [x] ln -s target link: Soft Symlink (Shortcut, xuyên ổ đĩa)
