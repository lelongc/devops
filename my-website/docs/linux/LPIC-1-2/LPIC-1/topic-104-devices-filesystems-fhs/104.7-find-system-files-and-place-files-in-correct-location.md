# 🐧 Objective 104.7: Chuẩn Phân Cấp FHS & Tìm Kiếm File (find & locate) - Bản Chất Hệ Thống & Thực Chiến DevOps

> 💡 **Bản chất 1 câu**: Nắm chắc cấu trúc các thư mục chuẩn FHS (`/etc`, `/var`, `/tmp`, `/usr`) và thành thạo công cụ tìm kiếm file mạnh mẽ `find`.  
> 🎯 **Trọng tâm phỏng vấn DevOps**: Tiêu chuẩn Filesystem Hierarchy Standard (FHS), lệnh find (-name, -type, -mtime, -exec), locate, which.

---

## 1. 🧠 Hình Hình Dung Nhanh (Intuitive Mindset)

`which` tìm vị trí lệnh thực thi (`which python3`). `locate` tìm siêu nhanh qua DB đánh chỉ mục. `find` là công cụ quét đĩa thật mạnh nhất tìm theo mọi điều kiện.

---

## 2. 📚 Lý Thuyết Chuyên Sâu & Bản Chất Hệ Thống (Under The Hood Mechanics)

### 2.1 Bản Chất Chuẩn FHS & Tìm Kiếm File
- **Filesystem Hierarchy Standard (FHS)**:
  - `/etc`: File cấu hình hệ thống tĩnh.
  - `/var`: Dữ liệu biến đổi (log `/var/log`, docker `/var/lib/docker`, mail).
  - `/usr`: Phần mềm hệ thống (`/usr/bin`, `/usr/lib`).
  - `/opt`: Phần mềm bên thứ ba cài thêm.
- `find`: Duyệt cây thư mục đĩa thật. `find /dir -type f -name '*.log' -mtime +30 -exec rm -f {} \;`


---

## 3. ⚡ Bảng Tra Cứu Câu Lệnh Thực Hành (CLI Command Reference)

| Câu lệnh | Tham số (Options/Flags) | Giải thích ý nghĩa chi tiết | Ví dụ thực tế trong DevOps |
| :--- | :--- | :--- | :--- |
| **`find`** | `Tìm kiếm file thực tế trên ổ đĩa` | -name, -type, -mtime, -exec | `find /var/log -name '*.log' -mtime +30 -delete` |
| **`which`** | `Tìm đường dẫn file thực thi của lệnh` | Không | `which docker` |
| **`locate`** | `Tìm file nhanh qua cơ sở dữ liệu` | Không | `locate nginx.conf` |


---

## 4. 🛠 Thao Tác Thực Chiến & Kịch Bản DevOps (Real-World Scenarios)

### 🛠 Các lệnh thực hành gõ là ăn ngay:
```bash
# Tìm và xóa log cũ hơn 30 ngày:
sudo find /var/log -type f -name '*.log' -mtime +30 -exec rm -f {} \;
```

### 🚀 Kịch bản xử lý sự cố thực tế khi đi làm:
Tìm file > 100MB:
find / -type f -size +100M

## 5. 🚀 Bộ Câu Hỏi Phỏng Vấn DevOps Thực Tế (Interview Q&A)

> **Q: Thư mục nào theo chuẩn FHS chứa các tệp tin cấu hình hệ thống?**  
> **A**: Thư mục `/etc/`.

> **Q: Lệnh find nào tìm và xóa tất cả các file .tmp trong /tmp?**  
> **A**: Lệnh `find /tmp -name '*.tmp' -delete`.
