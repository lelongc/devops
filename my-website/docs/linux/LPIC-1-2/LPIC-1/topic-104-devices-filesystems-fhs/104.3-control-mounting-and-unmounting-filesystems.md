# 🐧 Objective 104.3: Gắn Mount Ổ Đĩa & File /etc/fstab - Bản Chất Hệ Thống & Thực Chiến DevOps

> 💡 **Bản chất 1 câu**: Gắn (mount) phân đĩa vào cây thư mục Linux, tháo (umount) an toàn và cấu hình mount tự động khi boot bằng UUID trong `/etc/fstab`.  
> 🎯 **Trọng tâm phỏng vấn DevOps**: Lệnh mount, umount, blkid (lấy UUID), file /etc/fstab (6 trường cấu hình).

---

## 1. 🧠 Hình Hình Dung Nhanh (Intuitive Mindset)

Mount như cắm ổ USB vào máy tính: Phải chỉ định cắm vào thư mục nào (`/mnt/data`). Muốn máy tự cắm lại mỗi khi khởi động thì khai báo UUID vào sổ tay `/etc/fstab`.

---

## 2. 📚 Lý Thuyết Chuyên Sâu & Bản Chất Hệ Thống (Under The Hood Mechanics)

### 2.1 Bản Chất Lớp VFS & Mount Table
- Linux Virtual File System (VFS) hợp nhất mọi phân đĩa thành một cây thư mục gốc duy nhất (`/`).
- `/etc/fstab` có 6 trường: `Device/UUID`, `Mount Point`, `Filesystem Type`, `Mount Options`, `Dump (0/1)`, `Fsck Pass (0/1/2)`.


---

## 3. ⚡ Bảng Tra Cứu Câu Lệnh Thực Hành (CLI Command Reference)

| Câu lệnh | Tham số (Options/Flags) | Giải thích ý nghĩa chi tiết | Ví dụ thực tế trong DevOps |
| :--- | :--- | :--- | :--- |
| **`mount`** | `Gắn phân đĩa vào một thư mục` | -t, -o | `sudo mount /dev/sdb1 /mnt/data` |
| **`umount`** | `Tháo gắn phân đĩa an toàn` | Path | `sudo umount /mnt/data` |
| **`blkid`** | `Xem mã định danh UUID của các phân đĩa` | Không | `sudo blkid` |


---

## 4. 🛠 Thao Tác Thực Chiến & Kịch Bản DevOps (Real-World Scenarios)

### 🛠 Các lệnh thực hành gõ là ăn ngay:
```bash
# Thêm vào /etc/fstab:
UUID=a1b2c3d4-xxxx  /data  ext4  defaults  0  2

# Test mount:
sudo mount -a
```

### 🚀 Kịch bản xử lý sự cố thực tế khi đi làm:
Mount đĩa EBS AWS:
sudo mount -a

## 5. 🚀 Bộ Câu Hỏi Phỏng Vấn DevOps Thực Tế (Interview Q&A)

> **Q: File nào chứa cấu hình mount phân đĩa tự động khi khởi động hệ thống?**  
> **A**: File `/etc/fstab`.

> **Q: Tại sao nên dùng UUID trong /etc/fstab?**  
> **A**: Vì UUID là mã duy nhất không thay đổi khi thêm bớt đĩa.
