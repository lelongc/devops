# 🐧 Objective 104.1: Phân Đĩa & Định Dạng Filesystem (fdisk & mkfs) - Bản Chất Hệ Thống & Thực Chiến DevOps

> 💡 **Bản chất 1 câu**: Phân biệt chuẩn phân đĩa MBR vs GPT, tạo phân đĩa bằng `fdisk/gdisk` và định dạng hệ thống tệp `mkfs.ext4` hoặc `mkfs.xfs`.  
> 🎯 **Trọng tâm phỏng vấn DevOps**: MBR (<2TB, max 4 primary) vs GPT (>2TB, 128 partitions), fdisk, gdisk, mkfs.ext4, mkfs.xfs.

---

## 1. 🧠 Hình Hình Dung Nhanh (Intuitive Mindset)

Tạo ổ đĩa giống như xây nhà: `fdisk/gdisk` là chia phòng (Partitions), `mkfs` là lát gạch nền nhà (Filesystem ext4/xfs) thì mới chứa đồ đạc (files) được.

---

## 2. 📚 Lý Thuyết Chuyên Sâu & Bản Chất Hệ Thống (Under The Hood Mechanics)

### 2.1 Bản Chất Cấu Trúc Partition & Filesystem
- **MBR**: Giới hạn 2TB, tối đa 4 Primary Partition.
- **GPT**: Hỗ trợ đĩa > 2TB, tối đa 128 Partition.
- **Ext4 vs XFS**: Ext4 có Journaling tin cậy cho dữ liệu nhỏ; XFS dùng cấu trúc B-tree tối ưu cho file dữ liệu cực lớn và song song hóa I/O cao.


---

## 3. ⚡ Bảng Tra Cứu Câu Lệnh Thực Hành (CLI Command Reference)

| Câu lệnh | Tham số (Options/Flags) | Giải thích ý nghĩa chi tiết | Ví dụ thực tế trong DevOps |
| :--- | :--- | :--- | :--- |
| **`fdisk`** | `Quản lý phân đĩa MBR chuẩn cũ (<2TB)` | /dev/sdX | `sudo fdisk /dev/sdb` |
| **`gdisk`** | `Quản lý phân đĩa GPT chuẩn mới (>2TB)` | /dev/sdX | `sudo gdisk /dev/sdb` |
| **`mkfs.ext4`** | `Định dạng hệ thống tệp ext4` | /dev/sdX1 | `sudo mkfs.ext4 /dev/sdb1` |
| **`mkfs.xfs`** | `Định dạng hệ thống tệp XFS` | /dev/sdX1 | `sudo mkfs.xfs /dev/sdb1` |


---

## 4. 🛠 Thao Tác Thực Chiến & Kịch Bản DevOps (Real-World Scenarios)

### 🛠 Các lệnh thực hành gõ là ăn ngay:
```bash
# 1. Phân đĩa /dev/sdb:
sudo fdisk /dev/sdb

# 2. Định dạng ext4:
sudo mkfs.ext4 /dev/sdb1
```

### 🚀 Kịch bản xử lý sự cố thực tế khi đi làm:
Định dạng đĩa NVMe:
sudo mkfs.ext4 /dev/nvme0n1p1

## 5. 🚀 Bộ Câu Hỏi Phỏng Vấn DevOps Thực Tế (Interview Q&A)

> **Q: Chuẩn phân đĩa nào hỗ trợ dung lượng ổ đĩa lớn hơn 2TB?**  
> **A**: Chuẩn `GPT`.

> **Q: Lệnh nào định dạng một phân đĩa sang hệ thống tệp XFS?**  
> **A**: Lệnh `sudo mkfs.xfs /dev/sdb1`.
