# 🐧 Objective 109.3: Chẩn Đoán & Debug Sự Cố Mạng (ss, nc, tcpdump) - Bản Chất Hệ Thống & Thực Chiến DevOps

> 💡 **Bản chất 1 câu**: Bộ công cụ debug mạng huyền thoại của DevOps: `ping` (L3), `ss -tulpn` (xem Port mở L4), `nc -zvw3` (test Port từ xa), `tcpdump` (bắt gói tin).  
> 🎯 **Trọng tâm phỏng vấn DevOps**: Lệnh ss -tulpn (xem port lắng nghe), nc -zvw3 (test port), tcpdump -i port (bắt packet), curl -I (test HTTP).

---

## 1. 🧠 Hình Hình Dung Nhanh (Intuitive Mindset)

`ss -tulpn` xem cổng nào đang mở trên máy nhà. `nc -zvw3` đứng từ xa thò tay kiểm tra xem nhà đối phương có mở cổng không. `tcpdump` xem nội dung thư từ chạy trên đường cáp mạng.

---

## 2. 📚 Lý Thuyết Chuyên Sâu & Bản Chất Hệ Thống (Under The Hood Mechanics)

### 2.1 Bản Chất Socket State & Packet Sniffing
- `ss -tulpn`: Đọc trực tiếp từ Kernel Socket Table (`t`: TCP, `u`: UDP, `l`: Listen, `p`: Process PID, `n`: numeric port).
- `nc -zvw3 <ip> <port>`: Thử thiết lập TCP 3-way handshake với cờ SYN để test Firewall.
- `tcpdump`: Dùng AF_PACKET raw socket bắt gói tin trên card mạng (Packet capture).


---

## 3. ⚡ Bảng Tra Cứu Câu Lệnh Thực Hành (CLI Command Reference)

| Câu lệnh | Tham số (Options/Flags) | Giải thích ý nghĩa chi tiết | Ví dụ thực tế trong DevOps |
| :--- | :--- | :--- | :--- |
| **`ss`** | `Xem danh sách các Port đang lắng nghe kèm PID` | -tulpn | `sudo ss -tulpn | grep 80` |
| **`nc (netcat)`** | `Kiểm tra kết nối Port từ xa nhanh cực mạnh` | -zvw3 | `nc -zvw3 10.0.0.1 3306` |
| **`tcpdump`** | `Bắt và phân tích trực tiếp các gói tin mạng` | -i, port | `sudo tcpdump -i eth0 -n port 80` |
| **`curl`** | `Gửi request HTTP test Web API` | -I, -v | `curl -I https://google.com` |


---

## 4. 🛠 Thao Tác Thực Chiến & Kịch Bản DevOps (Real-World Scenarios)

### 🛠 Các lệnh thực hành gõ là ăn ngay:
```bash
# 1. Xem Port 80/443 có lắng nghe không:
sudo ss -tulpn | grep -E '80|443'

# 2. Test thông Port 3306 sang DB Server:
nc -zvw3 10.0.1.50 3306
```

### 🚀 Kịch bản xử lý sự cố thực tế khi đi làm:
Debug kết nối DB:
nc -zvw3 10.0.0.1 3306

## 5. 🚀 Bộ Câu Hỏi Phỏng Vấn DevOps Thực Tế (Interview Q&A)

> **Q: Lệnh hiện đại thay thế netstat để xem danh sách các Port đang lắng nghe?**  
> **A**: Lệnh `sudo ss -tulpn`.

> **Q: Làm sao test nhanh xem Server đối phương có mở Port 3306 hay bị Firewall chặn?**  
> **A**: Dùng lệnh `nc -zvw3 <IP_DB> 3306`.
