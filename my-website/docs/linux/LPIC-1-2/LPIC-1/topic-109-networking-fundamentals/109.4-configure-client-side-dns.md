# 🐧 Objective 109.4: Cấu Hình Phân Giải Tên Miền DNS Khách (/etc/resolv.conf & dig) - Bản Chất Hệ Thống & Thực Chiến DevOps

> 💡 **Bản chất 1 câu**: Cấu hình DNS Server trong `/etc/resolv.conf`, map IP thủ công trong `/etc/hosts` và tra cứu bản ghi DNS bằng `dig`.  
> 🎯 **Trọng tâm phỏng vấn DevOps**: File /etc/resolv.conf (nameserver 8.8.8.8), file /etc/hosts (IP mapping), lệnh dig (dig A, dig MX).

---

## 1. 🧠 Hình Hình Dung Nhanh (Intuitive Mindset)

`/etc/hosts` như cuốn danh bạ cá nhân (được ưu tiên tra cứu đầu tiên). `/etc/resolv.conf` như tổng đài 1080 DNS (nếu danh bạ cá nhân không có thì gọi tổng đài hỏi).

---

## 2. 📚 Lý Thuyết Chuyên Sâu & Bản Chất Hệ Thống (Under The Hood Mechanics)

### 2.1 Bản Chất Name Resolution Order (NSS Switch)
Thứ tự tra cứu tên miền được quyết định bởi `/etc/nsswitch.conf` dòng `hosts: files dns`.
1. `files`: Tra cứu file `/etc/hosts` trước.
2. `dns`: Tra cứu các IP `nameserver` định nghĩa trong `/etc/resolv.conf`.
- `dig google.com +short`: Gửi trực tiếp DNS UDP packet tới DNS Server để truy vấn bản ghi A record.


---

## 3. ⚡ Bảng Tra Cứu Câu Lệnh Thực Hành (CLI Command Reference)

| Câu lệnh | Tham số (Options/Flags) | Giải thích ý nghĩa chi tiết | Ví dụ thực tế trong DevOps |
| :--- | :--- | :--- | :--- |
| **`dig`** | `Tra cứu bản ghi DNS chi tiết chuyên sâu` | +short, A | `dig google.com A` |
| **`nslookup`** | `Tra cứu tên miền DNS đơn giản` | Domain | `nslookup devops.local` |

## 5. 🚀 Bộ Câu Hỏi Phỏng Vấn DevOps Thực Tế (Interview Q&A)

> **Q: File nào định nghĩa địa chỉ các máy chủ DNS Server (nameserver)?**  
> **A**: File `/etc/resolv.conf`.

> **Q: File nào cho phép map trực tiếp IP với Hostname cục bộ được ưu tiên tra cứu trước DNS?**  
> **A**: File `/etc/hosts`.
