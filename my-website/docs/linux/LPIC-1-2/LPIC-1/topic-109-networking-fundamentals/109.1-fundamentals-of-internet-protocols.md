# 🐧 Objective 109.1: Căn Bản Mạng Mát Tính, IP & Ports Cho DevOps - Bản Chất Hệ Thống & Thực Chiến DevOps

> 💡 **Bản chất 1 câu**: Tính toán IP, Subnet Mask CIDR (`/24`, `/16`), các cổng dịch vụ tiêu chuẩn (22 SSH, 80 HTTP, 443 HTTPS, 3306 MySQL, 53 DNS).  
> 🎯 **Trọng tâm phỏng vấn DevOps**: Mô hình TCP/IP, IPv4/IPv6, CIDR Subnetting (/24 = 255.255.255.0 = 256 IPs), Well-known Ports.

---

## 1. 🧠 Hình Hình Dung Nhanh (Intuitive Mindset)

CIDR Subnet `/24` nghĩa là giữ nguyên 24 bit đầu (3 số đầu), còn lại 8 bit làm IP cho máy (chứa tối đa 254 máy tính dùng được).

---

## 2. 📚 Lý Thuyết Chuyên Sâu & Bản Chất Hệ Thống (Under The Hood Mechanics)

### 2.1 Bản Chất TCP/IP & CIDR Subnetting
- **Mô hình TCP/IP**: Link -> Internet (IP) -> Transport (TCP/UDP) -> Application.
- **CIDR Subnetting**: `/24` = 255.255.255.0 (254 Usable IPs). `/16` = 255.255.0.0 (65534 Usable IPs).
- **Well-known Ports**: SSH (22), HTTP (80), HTTPS (443), DNS (53), MySQL (3306), Postgres (5432), Redis (6379).


---

## 4. 🛠 Thao Tác Thực Chiến & Kịch Bản DevOps (Real-World Scenarios)

### 🛠 Các lệnh thực hành gõ là ăn ngay:
```bash
# Tính dải IP của VPC Subnet /24:
ipcalc 10.0.1.0/24
```

### 🚀 Kịch bản xử lý sự cố thực tế khi đi làm:
Quy hoạch dải mạng Subnet AWS VPC:

## 5. 🚀 Bộ Câu Hỏi Phỏng Vấn DevOps Thực Tế (Interview Q&A)

> **Q: Dải mạng Subnet CIDR `/24` tương ứng với Subnet Mask nào?**  
> **A**: Tương ứng với `255.255.255.0`.

> **Q: Port mặc định của các dịch vụ SSH, HTTP và HTTPS lần lượt là gì?**  
> **A**: SSH (22), HTTP (80), HTTPS (443).
