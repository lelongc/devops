# 🐧 Objective 109.2: Cấu Hình Mạng Cố Định (Netplan & NetworkManager) - Bản Chất Hệ Thống & Thực Chiến DevOps

> 💡 **Bản chất 1 câu**: Cấu hình IP tĩnh/DHCP cố định trên Ubuntu với Netplan (`/etc/netplan/*.yaml`) và RHEL với NetworkManager (`nmcli`).  
> 🎯 **Trọng tâm phỏng vấn DevOps**: Netplan config YAML, lệnh netplan apply, NetworkManager công cụ nmcli.

---

## 1. 🧠 Hình Hình Dung Nhanh (Intuitive Mindset)

Netplan dùng file cấu hình YAML thụt lùi dòng bằng khoảng trắng (không dùng Tab). Sửa xong bắt buộc gõ `sudo netplan apply`.

---

## 2. 📚 Lý Thuyết Chuyên Sâu & Bản Chất Hệ Thống (Under The Hood Mechanics)

### 2.1 Bản Chất Netplan & NetworkManager Stack
Netplan là renderer cấu hình mạng trên Ubuntu: Đọc YAML `/etc/netplan/*.yaml` rồi biên dịch ra file cấu hình cho `systemd-networkd` hoặc NetworkManager. `nmcli` là CLI giao tiếp D-Bus với NetworkManager trên RHEL.


---

## 3. ⚡ Bảng Tra Cứu Câu Lệnh Thực Hành (CLI Command Reference)

| Câu lệnh | Tham số (Options/Flags) | Giải thích ý nghĩa chi tiết | Ví dụ thực tế trong DevOps |
| :--- | :--- | :--- | :--- |
| **`netplan apply`** | `Áp dụng ngay cấu hình mạng mới trên Ubuntu` | Không | `sudo netplan apply` |
| **`nmcli`** | `Quản lý mạng bằng NetworkManager CLI trên RHEL` | device, connection | `nmcli device status` |


---

## 5. 🚀 Bộ Câu Hỏi Phỏng Vấn DevOps Thực Tế (Interview Q&A)

> **Q: Lệnh nào áp dụng cấu hình mạng mới trên Ubuntu dùng Netplan?**  
> **A**: Lệnh `sudo netplan apply`.

> **Q: Công cụ CLI tiêu chuẩn quản lý mạng trên RHEL/CentOS là gì?**  
> **A**: Công cụ `nmcli`.
